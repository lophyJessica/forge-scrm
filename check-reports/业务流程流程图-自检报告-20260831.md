## 七、遗留风险

1. `index.html` 通过 jsDelivr 加载 Mermaid 和 marked，离线或受限网络环境不能渲染图形，但两份 Markdown 原文仍可查看。
2. 脚本库缺少独立《业务流程推演》文件；本文虽已按更高权威的 context、主 PRD、规则规格和代码交叉补齐，后续若新增正式推演需再次比对。
3. 后端仍保留内部过渡态，前端用 `displayStatus` 映射为用户可见状态；资料下游选择、脚本使用和分析回写仍依赖后端真实状态校验，需在联调中持续确认默认路径不会形成阻断。
4. `MainLayout` 对成员隐藏自动采集和研究菜单，但 `App.tsx` 的对应路由未使用管理员守卫；直接路径访问与菜单可见性并不等价。
5. 视频号、小红书官方接口、外部检索源、DeepSeek 稳定性、飞书授权和限流均属于外部依赖，文档不代表这些依赖已完成生产验证。
6. 文档是 2026-08-31 快照；后续按钮、路由、状态映射、菜单或二期流程变化时需同步更新两份 Markdown 和渲染验证。
