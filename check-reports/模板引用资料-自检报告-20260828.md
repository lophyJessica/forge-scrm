## 每个文件改动点

### backend/app/services/topic_service.py

- `build_prompt()` 在非自定义提示词的模板分支读取 `template.material_combo`。
- 模板资料 ID 放在调用方当场选择的 `material_ids` 前，使用 `dict.fromkeys()` 按首次出现顺序去重。
- 合并后的资料统一传入现有 `build_material_block()`，继续执行 R1“仅已生效资料可引用”校验。
- `build_material_block()` 按输入 ID 顺序重排数据库结果，保证实际提示词中的资料顺序为模板资料在前。
- 模板生成且实际引用资料时，提示词快照新增 `material_combo_snapshot`，逐项保存资料 `id`、`title` 和当时完整 `content`。
- 无引用资料时不增加该快照字段；自定义提示词和代码常量兜底逻辑保持原行为。

### frontend/src/components/MaterialComboField.tsx

- 新增两套模板页面共用的资料引用字段，避免重复实现加载与筛选逻辑。
- 并行请求现有 `/materials`、`/material-classes`、`/tags` 接口。
- 资料请求固定携带 `status=已生效` 和 `page_size=200`，不展示未生效资料供新增选择。
- 提供标题/正文关键词、资料分类和标签筛选。
- 使用 antd `Select mode="multiple"` 多选，已选项在切换筛选条件后仍保留并可移除。
- 字段标题和帮助文案严格采用 PRD 指定文本。

### frontend/src/pages/admin/PromptTemplates.tsx

- 新建/编辑弹窗接入 `MaterialComboField`。
- 保存 payload 增加 `material_combo` 资料 ID 数组。
- 编辑时继续通过现有 `form.setFieldsValue(row)` 回显已保存引用。

### frontend/src/pages/analysis/PromptTemplates.tsx

- 新建/编辑弹窗接入 `MaterialComboField`。
- 保存 payload 增加 `material_combo` 资料 ID 数组。
- 编辑时继续通过现有行数据回显已保存引用。
