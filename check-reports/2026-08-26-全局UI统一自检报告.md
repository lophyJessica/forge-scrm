## 3. 每类统一做了什么

### 3.1 紫色主题（对齐 copy-wms）

- `colorPrimary` / `colorLink` / `colorInfo` = `#7c3aed`
- `borderRadius` = 6
- 深色 Menu：`darkItemSelectedBg` = `#7c3aed`，悬停半透明紫
- 全站 primary 按钮、链接、选中、焦点随 ConfigProvider 变紫，无需逐页改色值

### 3.2 操作栏

- 表格按钮 `size="small"`，间距 8px
- 删除/废弃/驳回/回退：`type="link" danger`
- 超过 2 个操作收入「更多」Dropdown（资料列表、脚本列表、分析任务等）
- 启停用 Switch 从操作列移到状态列：提示词模板、成员账号、对标账号

### 3.3 状态 Tag 色板

- 启用/已通过/已生效/已完成/已选定/已确认 → green
- 停用/已废弃/失败/已过期 → red
- 待审核/待筛选/执行中/检索中/整理中 → orange
- 草稿/待执行 → default
- 部分成功 → gold

### 3.4 列表 / 表单 / 弹窗

- 列表 Card + 筛选 + Table，分页 `position: bottomRight`
- 长文本 ellipsis / Tooltip
- 表单 `layout="vertical"` + `maxWidth: 720`，取消在左、提交在右
- Modal：常规 520，多字段 720
