## 三、方案要点

1. **目录结构**：backend/（FastAPI + SQLAlchemy + Alembic，models/schemas/routers/services 分层）+ frontend/（React18 + TS + antd5 + Vite + zustand）。
2. **API 清单**：按模块列出约 45 个端点，全部标注方法、路径、功能、权限（对齐 context/06 权限矩阵，管理员/成员两级）。
3. **数据库**：对照核心字段清单确认 16 张表（user、material_class、material、tag、material_tag、prompt_template、topic、topic_material、script、script_version、data_source、raw_data、analysis_task、analysis_task_input、analysis_result、analysis_result_material、analysis_result_topic）；不建 topic_version（D8）、prompt_version（待确认）、material_version（待确认）。
4. **AI 设计**：DeepSeek 调用统一封装 deepseek_service；选题/脚本/分析三类 prompt 模板结构 + JSON schema + 校验（长度/枚举/非空）+ 失败重试 3 次指数退避 + ai_raw_response 全量留档。
5. **前端页面**：9 个页面组约 24 个路由，对齐 antd 组件；路由守卫 + 角色控制。
6. **开发顺序**：后端 5 步（基础设施 → 资料库 → 选题脚本+AI → 数据分析 → 前端全模块），前端可并行。
7. **风险**：5 项待澄清（分析任务异步方式、有效期过期检测、JWT 刷新、CSV 列映射、对象存储）；3 项默认决策已向用户说明。
