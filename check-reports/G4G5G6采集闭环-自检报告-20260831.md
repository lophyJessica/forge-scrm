# G4/G5/G6 采集闭环自检报告

日期：2026-08-31

## 1. 本轮结果

- G4 重复任务提示：已实现。创建采集任务时按 `scope_type`、规范化账号集合、采集范围和时间窗生成 SHA-256 幂等键；命中已有任务返回 HTTP 409 结构化冲突信息。前端展示任务编号、状态、创建时间和结果数，只提供“查看旧任务”，不提供 PRD 尚未确认的强制创建入口。
- G5 记录级重试：已实现。失败且 `retryable=true` 的记录显示“重试”；后端保留旧失败尝试，新增 `attempt_no + 1` 的记录执行，成功时仅保留该任务/账号的一条成功结果，任务计数随后刷新。
- G6 结果进入资料库/数据分析：已实现。结果表提供“沉淀为资料”和“作为分析输入”；资料沉淀使用既有资料字段口径并沿用结果的 `is_ai_product` 标记（原始采集结果保持 false），分析创建支持 `collection_result_ids` 与 `raw_data_ids` 并列输入，执行器会把采集结果原文和结构化数据拼入分析输入。

## 3. 新增/扩展接口

| 方法 | 路径 | 鉴权 | 幂等/约束 |
|---|---|---|---|
| POST（扩展） | `/api/collection-tasks` | `CurrentUser`，沿用采集模块授权 | 同账号集合、同时间窗、同范围使用规范化 SHA-256 键；重复返回 409 和已有任务摘要；停用/不存在账号不能创建 |
| POST | `/api/collection/records/{record_id}/retry` | `CurrentUser` | 仅失败且可重试记录；保留旧记录并递增 `attempt_no`；成功结果按任务/账号唯一约束防重复 |
| POST | `/api/collection-results/{result_id}/material` | `CurrentUser`；分类数据范围沿用 `assert_material_class_visible`；新标签沿用 `Permission.标签创建` | 新建资料为草稿、`source_type=对标`、沿用结果 `is_ai_product`；来源链接遵守资料字段 500 字符限制 |
| POST（扩展） | `/api/analysis-tasks` | `Permission.分析任务执行` | `raw_data_ids` 与 `collection_result_ids` 至少一类非空；输入关联分别去重 |

## 4. G6 待拍板项与保守默认

- 资料分类归属：由用户在沉淀表单选择；未增加新的分类枚举。
- `source_type`：暂按已有“对标”枚举；若产品决定采用其他来源类型再调整。
- 可信度：默认“中”。
- 有效期：默认今天至一年后，仍允许用户修改。
- 资料状态：默认草稿，未增加前端流程入口。
- AI 产物标记：直接沉淀原始采集结果保持 `false`；若输入结果本身已标记为 AI 产物，则资料同步保留 `true`。
- 采集结果与资料之间：未新增未在 context 定义的关联字段，来源追溯仍通过内容/来源链接保留。
- 重复沉淀同一采集结果是否需要专门幂等键/关联表，PRD 未明确，本轮未虚构字段；当前每次明确操作都会新建一条草稿资料。
