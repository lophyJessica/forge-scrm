# 脚本列表卡片根因修复自检报告

日期：2026-08-31  
范围：仅修复 `frontend/src/pages/scripts/ScriptList.tsx`，未修改后端、主题 token 或其他列表页。

## 1. 运行时证据

线上页面：`https://scrm.pmlophy.com/scripts`

- 页面仅渲染 1 个筛选 `<form>`。
- Form class：`ant-form ant-form-inline css-1ossgrg`。
- 父级链：`form.ant-form.ant-form-inline` → `div.ant-card-body` → `div.ant-card.ant-card-bordered` → `div.forge-page`。
- 输入 placeholder：`正文关键词`、`选题 ID`，另有两个搜索控件（语言风格、状态）。
- 线上 `/scripts` Form `style` 属性为 `null`；computed style 为 `background: rgba(0, 0, 0, 0)`、`border: 0px none`、`border-radius: 0px`、`padding: 0px`、`margin-bottom: 0px`。
- 对照页面 `/materials` 使用同一 `FILTER_CARD_STYLE`，线上 Form 可见 `#fafafa` 背景、`1px solid #f0f0f0` 边框、8px 圆角、16px 内边距和 24px 下边距。
- 浏览器 Playwright 评估桥接会隐藏 React 私有 `__reactFiber$*` / `__reactProps$*` expando（目标 Form `Reflect.ownKeys` 无 React key），因此无法从该桥接读取 `pendingProps.style`；没有伪造 Fiber 层证据。
- 源码、路由和构建产物交叉确认：`/scripts` 为 `App.tsx` 唯一路由入口，`frontend/src/pages/scripts/` 只有一个 `ScriptList.tsx`，无懒加载、重复副本、`cloneElement`、DOM style 操作；构建 bundle 的脚本模块确实包含 `style:Ji`，且 `Ji` 为完整 token 对象。

## 2. 根因结论

可观测根因位于 React/Antd Form props 到原生 `<form>` 的运行时传递层；结合脚本页独有的复现现象，推断跨列表路由复用 Form 节点时共享 style 对象未重新写入 DOM（React 私有 Fiber 受浏览器桥接隔离，无法进一步读取内部复用链）。

## 3. 修复方式与改动文件

`frontend/src/pages/scripts/ScriptList.tsx`

- 从 `FILTER_CARD_STYLE` 创建页面内独立对象 `filterCardStyle`，仍以 `theme.ts` token 为唯一来源。
- 为筛选 Form 增加稳定页面专属 `key="scripts-filter"`，确保脚本列表 Form 独立挂载，不复用其他列表的 Form fiber。
- 未改筛选字段、请求参数、分页、状态映射或任何其他页面。
