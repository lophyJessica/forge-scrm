## 3. 关键改动

### 3.1 报告实体

统一 `report` 表，`report_type` 区分运营数据报告 / 市场分析周报。生成状态：待生成 → 生成中 → 已完成/失败。`is_ai_product` 默认 true（R8）。来源快照写入 `source_snapshot`（类型+id），对应指令中的 data_source_summary。

### 3.2 生成聚合

- 运营数据报告：已确认分析任务结果 + 周期内采集结果 + 业务原始数据
- 市场分析周报：研究助手报告 + 采集结果 + 外部检索引用
- 周期内无任何可用来源 → 失败（`EMPTY_SOURCE`），不伪造指标
- 部分来源缺失写入 `gaps`，结论只基于已有来源
- 重试：仅失败可重试；`retry_count+1`；旧错误进入 `generation_trace.error_history`；已完成再次生成/重试 409

### 3.3 推送骨架

已完成报告可创建 `report_push_task`（飞书/微信 + 目标标识）。`POST /api/push-tasks/{id}/execute` 返回 **501**，任务记为失败并写 `CHANNEL_API_NOT_IMPLEMENTED`，不伪装已推送。TODO：渠道 API 待实测。

### 3.4 前端

菜单并入「数据分析」二级。列表 Card + 筛选 + 分页靠右；失败显示重试；详情展示来源清单与 AI 标记。操作栏/状态 Tag 走全局紫色主题色板。
