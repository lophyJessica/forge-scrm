## 接口定义

### `GET /api/topics/export`

- 鉴权：`CurrentUser`，与 `GET /api/topics` 相同。
- 查询参数：`keyword`、`direction`、`specialty`、`status`、`batch_no`；与列表页筛选参数一致。
- 排序：`created_at DESC, id DESC`，与列表接口一致。
- 成功响应：CSV 文件；`Content-Type: text/csv; charset=utf-8`，内容以 UTF-8 BOM 开头。
- 下载响应头：`Content-Disposition: attachment; filename="topic_export.csv"`（前端下载时使用用户可见日期文件名）。
- 超限响应：匹配结果超过 5000 行时返回 HTTP 400，提示“请缩小筛选范围后重试”，不构造 CSV 内容。

## CSV 列清单与字段口径对照

| CSV 列 | 数据来源 | context/05 口径 |
|---|---|---|
| ID | `topic.id` | 选题 id（主键） |
| 标题 | `topic.title` | 标题 |
| 方向 | `topic.direction` | 方向/分类 |
| 状态 | `topic.status` 经用户可见映射 | 状态；不输出后端预留态文字 |
| 来源 | 由 `topic.batch_no` 派生 | 批量生成路径或独立/手动创建路径；不新增字段 |
| 生成批次 | `topic.batch_no`，独立创建为空 | 生成批次（可选，保留历史） |
| 创建时间 | `topic.created_at`，秒级 ISO 文本 | 创建人/创建时间中的创建时间 |

来源派生规则：有 `batch_no` 输出“批量生成”，无 `batch_no` 输出“独立创建”。该列是现有字段的展示映射，不改变模型或枚举。

## 行数上限策略

导出前先执行与筛选条件一致的 `COUNT(*)` 查询；结果大于 `TOPIC_EXPORT_MAX_ROWS = 5000` 时立即抛出业务错误，避免一次性加载超限数据。通过后按列表同样的时间倒序读取全部结果并生成 CSV。
