# 列表页筛选区卡片化 — 指令

> 日期：2026-08-31
> 依据：用户 0831 实测反馈——全站列表页筛选区与表格"挤在一起"，16→24px 视觉提升不明显，拍板方案 A：筛选区卡片化
> 范围：仅前端，8 个列表页统一。禁止改后端。

## 指令正文（复制给 Codex，独立会话）

```plaintext
cd forge-scrm 仓库根目录（Mac 本地实际路径），不新建任何目录。开工前先 git pull origin main。

Context:
全站 8 个列表页结构统一为 Card 包裹 → inline Form（筛选区）→ Table。现行筛选区与表格间距 24px（UI-DESIGN.md L 档），但用户实测观感仍"挤在一起"。用户拍板方案 A：筛选区卡片化——给筛选区加浅灰背景+内边距+圆角，与表格形成明确区块分层。间距规范保持 24px 不变。

Request:
在 frontend/src/theme.ts 定义一个全局导出常量（单一来源，8 页复用同一 token，禁止各页自写样式）：

export const FILTER_CARD_STYLE: React.CSSProperties = {
  background: '#fafafa',
  border: '1px solid #f0f0f0',
  borderRadius: 8,
  padding: 16,
  marginBottom: 24,
}

（颜色取 antd 默认灰阶，与主题无冲突；padding 16 = M 档；marginBottom 24 = L 档，符合 UI-DESIGN.md 间距规范。）

然后对以下 8 个列表页的筛选 Form 统一应用 style={FILTER_CARD_STYLE}（替换现有 style={{ marginBottom: 24 }}）：
1. frontend/src/pages/materials/MaterialList.tsx (:83)
2. frontend/src/pages/topics/TopicList.tsx (:65)
3. frontend/src/pages/analysis/AnalysisTasks.tsx (:106)
4. frontend/src/pages/reports/ReportList.tsx (:306)
5. frontend/src/pages/collection/CollectionTasks.tsx (:249)
6. frontend/src/pages/research/ResearchTasks.tsx (:97)
7. frontend/src/pages/scripts/ScriptList.tsx (:65)
8. frontend/src/pages/scripts 下若存在其他列表结构页（如版本对比列表）一并检查，结构相同则同改。

注意：
- AnalysisTasks/ReportList 内部的 marginBottom: 16 是非筛选区块（如 Alert/其他），不动。
- 只改筛选 Form 的容器样式，不改任何筛选逻辑、查询参数、Form.Item。
- inline Form 在卡片内若出现换行拥挤，可为 Form.Item 之间留默认间距即可，禁止改 width。

红线禁止:
- 禁止修改 backend/
- 禁止改动查询/筛选/分页逻辑
- 禁止在页面内自写平行样式（必须引用 theme.ts 的 FILTER_CARD_STYLE）
- 禁止 commit/push/部署
- 遵守 AGENTS.md 工作流铁律

Checkpoint:
完成后生成自检报告 check-reports/筛选区卡片化-自检报告-20260831.md，含：改动文件清单、每页引用 FILTER_CARD_STYLE 的行号、npm run build + tsc 通过证明、8 页截图或布局说明（至少说明视觉前后差异）。沙箱网络受限则报告留本地，由杰西卡代传管道。
```
