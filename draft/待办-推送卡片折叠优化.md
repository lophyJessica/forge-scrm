# 推送卡片折叠优化 — 待办（P2 体验优化）

> 状态：已确认待办，下轮迭代执行
> 日期：2026-08-28
> 来源：用户实测反馈——卡片正文全部平铺，报告一长卡片就"一屏全是字"，希望默认收起、点击展开。

## 需求

飞书推送卡片改为**折叠式**：默认只显示「生成时间 + 摘要 + 数据概览」，**报告正文默认折叠**，用户点击「展开正文」再显示全部。

## 技术要点

- 飞书卡片 2.0（card JSON 2.0）支持 `collapsible_panel` 折叠容器组件（可设默认收起 + 标题行），这是正解；需确认项目内 lark_oapi/卡片版本支持情况
- 兜底方案（若折叠组件不可用）：正文压缩为前 N 字 + 卡片 action 按钮不放（不跳系统），或 header 下挂 markdown 摘要版正文
- 现有 28KB 截断逻辑保留（折叠容器内同样受卡片总体积限制）
- elements 结构变化：`div(时间) → div(摘要) → div(概览) → collapsible_panel(正文, default_collapsed=true)`

## 验收

1. 收到卡片首屏只见概览信息，正文收起
2. 点击展开能看到正文全文（或截断版+提示）
3. 手机端飞书展示正常
