# Forge 新媒体运营系统：业务调研结论

> 来源：调研者填写版需求调研问卷（2026-08-23）
> 文档性质：基于问卷回复的已确认事实整理；未确认项明确标注，不视为最终规则。

## 一、账号与业务定位（已确认）

| 项目 | 结论 |
|---|---|
| 目标客户 | 中小微企业主，不设行业边界；常见场景：企业服务、招商加盟、教育培训 |
| 核心目标 | 获客、建立专业形象、引流到私域 |
| 平台 | 微信视频号、小红书；抖音/公众号未勾选 |
| 内容方向 | 企业线上营销与获客：市场营销、企业经营、自媒体平台流量与算法逻辑、用户洞察与需求/买点 |
| 内容主题 | 获客问题、误区、案例片段、企业线上增长痛点 |
| 用户行动目标 | 首要：咨询、加微信；次要：关注、转发 |
| 差异化优势 | 懂业务与经营、懂客户洞察、擅长营销结合，帮企业找真问题和有效解法 |

## 二、资料库（已确认）

### 资料类型与来源方式

| 资料类型 | 手动整理 | 自动采集 | AI 分析 | 仅人工添加 |
|---|---|---|---|---|
| 商业研究结论 | ✅ | | | ✅ |
| 个人观点 | ✅ | | | ✅ |
| 案例/案例包装 | ✅ | | | ✅ |
| 用户评论与私信 | | ✅ | ✅（用户洞察分析） | |

| 行业报告 | | ✅ | ✅（长报告提炼） | |
| 实时热点（与定位相关） | | ✅ | ✅（热点解读） | |

### 资料管理规则（已确认）

- 资料来源：公众号/网页文章、行业报告、社交媒体、客户沟通记录、自己的思考总结、对标账号内容
- 来源链接：视情况而定
- 有效期 + 可信度：都需要记录
- 审核：需要审核后才能使用
- 分类（已勾选）：商业研究结论、案例包装、评论和私信、个人观点、对标账号分析、相关热点
- 调用方式：提示词中按固定组合调用部分资料（如 商业研究结论 + 个人观点 + 案例）
- 优先建立：尽可能同步建立

- 标签维度（是否需要标签、按什么维度）：待确认
- 资料条目的具体数据来源实现方式

## 三、选题库（已确认）

- 产生方式：AI 生成 + 自己想
- 生成方式：批量，一次多个
- 数量规则：按不同方向，每个方向 10 个；任务可重复执行；保留历史记录；**不同批次结果要避免重复（跨批次去重）**
- 生成参考：指定分类的资料、最近热点、对标账号近期内容、客户常见问题
- 分类体系（已确认）：
  - 专业知识：市场营销、企业经营、自媒体平台流量与规划算法逻辑、用户需求与痛点
  - 需求及链条：结合需求场景、用户视角、其他待补充
  - 叠加维度（非独立分类）：选题原则、选题角度、经营方向
- 需结合客户场景：是
- 需从用户视角出发：是
- 需区分原则/角度/经营方向：是
- 审核：必须人工筛选后再用
- 状态：待筛选、已生成脚本、已废弃
- 判断"可以用"：人工判断

## 四、脚本库

### 已确认

- 每个选题生成 2-3 个脚本版本供挑选
- 生成时调用：选题关联的资料
- 语言风格：专业严谨、轻松口语、讲故事（均可）
- 内容要素：案例、数据、个人观点都需要
- 人工修改：偶尔改
- 状态：待审核、已通过、已废弃

## 五、数据分析

### 已确认

- 分析数据范围：全维度
- 平台：微信视频号（问卷勾选）
- 对象：自己账号 + 对标账号都要
- 自动采集：常规全量数据；无法自动采集时接受手动填写
- 分析周期：不固定
- 输出字段：尽可能全部字段
- 结论形态：效果好坏、分析结论、建议
- 查看人：账号操盘手
- 审核：结果需要人工审核后才能使用
- 回写资料库：需要（形成知识积累）
- 生成新选题：需要（数据反哺内容方向）

## 六、系统使用方式

### 已确认

- 使用者：账号操盘手
- 目前只有操盘手一人，未来可能有其他人
- 新增/修改资料：操盘手 + 指定成员
- 审核选题/脚本：操盘手 + 指定成员

## 七、一期 MVP 范围

### 必须有（一期上线）

1. 资料库手动添加
2. 资料分类和标签
3. 资料搜索和调用
4. 选题生成
5. 脚本生成
6. 手动录入数据
7. 数据分析
8. 自动采集

### 希望有（一期尽量有）

- 选题审核
- 脚本修改和版本
- CSV/TXT 导入

### 可以后做（二期）

- 脚本审核
- 结果导出
- 账号和权限
- 操作记录

## 八、补充说明（已确认）

当前最希望系统解决：

1. 采集外部信息；

3. 重复执行批量生成选题和脚本（要避免重复）；
4. 数据分析。
