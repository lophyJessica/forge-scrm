# Context

本目录用于保存已经确认的业务事实、术语、范围、角色、规则和系统边界。

当前项目仍处于需求调研阶段，正式业务事实尚未完成确认。

## 使用规则

- 未经用户或业务负责人确认的内容不得写入本目录；
- 初步设想放入 `draft/` 或 `requirements/`；
- 修改本目录后必须同步检查相关需求文档和正式 PRD；
- 不在 `prd-docs/` 单独创造与本目录冲突的业务规则。

## 当前状态

待业务问题调研完成后建立：

- 项目范围与目标；
- 角色与使用者；
- 资料库术语和分类；
- 选题、脚本和分析术语；
- 数据来源与采集边界；
- 状态和审核规则；
- 系统与自动化平台边界。
