# 术语与字段口径

> 状态：✅ 已确认核心口径（标签库灵活创建、脚本历史保留等，2026-08-24 回写）
> 权威层级：context/ > templates/ > prd-docs/
> 说明：字段口径是 SSOT（唯一事实源），Demo/PRD 只引用不重复定义。

## 1. 术语表

| 术语 | 定义 |
|---|---|
| 资料库 | 可被选题/脚本/分析调用的资料集合 |
| 资料分类 | 资料类型分类（见 2.1） |
| 资料标签 | 多维度打标能力（维度待确认） |
| 选题 | 内容方向，批量生成 + 人工筛选 |
| 方向/分类 | 选题的专业维度（营销/企业/用户/需求链条/场景/视角/经营方向等） |
| 脚本 | 口播/图文内容脚本，每选题多版本 |
| 分析任务 | 一次数据分析执行（含提示词+资料上下文）
| 分析结果 | 结构化输出 + 结论，需人工审核 |
| 账号操盘手 | 系统主要使用者（姐夫本人或其指定成员） |
| 对标账号 | 同类/竞争账号，用于采集+分析 |

## 2. 资料分类枚举（已确认）

- 商业研究结论
- 案例包装
- 评论和私信
- 个人观点
- 对标账号分析
- 相关热点

补充说明：问卷勾选的分类即一期枚举；可扩展（后续可加"业务/定位/画布/实际案例/用户量"等）。

## 3. 选题分类维度（已确认）

### 3.1 专业知识分类

- 市场营销
- 企业经营
- 自媒体平台流量与规划算法逻辑
- 用户需求与痛点

### 3.2 需求及需求链条

- 结合需求场景
- 用户视角
- 其他待补充

### 3.3 叠加维度（非独立分类）

- 选题原则
- 选题角度
- 经营方向
