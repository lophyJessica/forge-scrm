# 资料库_业务流程推演

> 文件定位：资料从进入系统到被下游引用的沙盘推演
> 配套：资料库主PRD.md / 资料库_业务规则规格.md / 资料库_用例数据推演.md

## 一、主流程：手动新增并生效

```text
新建资料
→ 填标题/正文/分类/来源/可信度/有效期/标签
→ 存为草稿
→ 提交审核（待审核）
→ 人工审核通过（已生效）
→ 出现在资料列表和下游“已生效资料”选择器
→ 被选题/脚本/分析任务引用
```

## 二、批量导入流程

```text
下载固定模板
→ 上传 CSV/TXT
→ 文件级格式检查
→ 逐行字段/枚举/日期校验
├─ 成功行：创建资料（待审核）
└─ 失败行：记录行号+原因
→ 展示成功/失败计数和原文件路径
→ 成功资料进入审核队列
```

## 三、AI 结果回写流程

```text
分析任务已确认
→ 用户选择“回写资料库”
→ 编辑候选资料字段
→ 创建资料：is_ai_product=true + source_analysis_task_id
→ 状态=待审核
→ 审核通过后成为已生效资料
```

## 四、生命周期推演

```text
已生效资料 A
├─ 人工停用 → 已停用 → 重新启用 → 已生效
└─ 到达有效期止 → 已过期 → 人工确认 → 已废弃

任何非“已生效”状态：不得进入选题/脚本/分析的资料选择器。
```

## 五、边界场景

### 场景 A：导入 10 行，2 行失败

```text
总行数 10
成功 8：分别进入待审核
失败 2：第4行分类不存在；第7行有效期止为空
结果：成功行保留，失败行不创建脏数据
```

### 场景 B：AI 回写绕过审核

```text
分析结果已确认 → 回写成功 → 资料为待审核
下游查询 status=已生效 → 不返回该资料
结论：R8 闭环成立
```

### 场景 C：已生效资料到期

```text
valid_until=2026-08-23，系统日期=2026-08-24
状态检查后：已生效 → 已过期
选题生成资料选择器：不返回该资料
```
