# 资料库_Demo_列表页

> 文件定位：现有 `MaterialList.tsx` 页面规格
> 路由：`/materials`
> 原则：本文件描述当前页面；业务约束仍以 context 为准

## 一、页面结构

```text
Card：资料列表
├─ 右上：[批量导入] [新建资料]
├─ 查询区：关键词 / 分类 / 标签 / 状态 / [查询] [重置]
├─ 资料表格（服务端分页，每页20）
└─ 点击标题：资料详情 Modal
```

## 二、查询控件

| 控件 | 实际字段/来源 | 行为 |
|---|---|---|
| 关键词 Input | keyword | 标题/正文关键词 |
| 分类 Select | `/material-classes` | 可清空 |
| 标签 Select | `/tags` | 可搜索、可清空 |
| 状态 Select | meta `material_status` | 使用服务端枚举 |
| 查询/重置 | `/materials` | 重置后回第1页 |

## 三、表格列

| 列 | 字段/表现 |
|---|---|
| ID | id |
| 标题 | title；AI 产物追加紫色 Tag；点击开详情 Modal |
| 分类 | class_name |
| 标签 | tags 多个 Tag |
| 来源 | source_type |
| 可信度 | trust_level |
| 有效期 | valid_from ~ valid_until |
| 状态 | status Tag |
| 操作 | 编辑及状态动作 |

状态颜色：草稿 default、待审核 orange、已生效 green、已停用 volcano、已过期 red、已废弃 default。

## 四、实际行内操作

| 状态 | 当前按钮 |
|---|---|
| 草稿 | 编辑、提交审核、按权限删除 |
| 待审核 | 编辑、按权限删除 |
| 已生效 | 编辑、停用、按权限删除 |
| 已停用 | 编辑、启用、按权限删除 |
| 已过期 | 编辑、确认废弃、按权限删除 |
| 已废弃 | 编辑、按权限删除 |

删除按钮由 `PERM.材料删除` 控制。编辑按钮当前未单独做前端权限隐藏，后端仍应按权限矩阵校验。

## 五、详情入口

当前没有独立详情路由。点击标题打开 `Modal(width=760)`，内容见 `资料库_Demo_详情页.md`。

## 六、加载与空态

- Table 使用 loading 状态。
- 无显式自定义空态，使用 Ant Design Table 默认空态。
- API 错误由全局拦截器 message 提示。

## 八、实现差异

- 已生效资料编辑后的再审策略未确认，页面当前允许直接进入编辑页。
- 删除被引用资料的保护策略未在 SSOT 定义，不能仅依据按钮存在推导规则。
