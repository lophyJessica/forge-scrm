## 一、核心用例表

| 用例 | 前置 | 操作 | 期望结果 |
|---|---|---|---|
| TC-M01 保存草稿 | 已登录 | 填完整资料，点存为草稿 | 状态=草稿 |
| TC-M02 提交审核 | TC-M01 | 点提交审核 | 状态=待审核 |
| TC-M03 审核通过 | 待审核 | 点通过 | 状态=已生效，可被引用 |
| TC-M04 审核驳回 | 待审核 | 点驳回 | 状态=已废弃 |
| TC-M05 自由标签 | 新增页 | 输入新标签并回车 | 标签创建并选中，标签组可空 |
| TC-M06 搜索 | 有多分类资料 | 组合关键词/分类/标签/状态 | 返回正确集合 |
| TC-M07 停用启用 | 已生效 | 停用后再启用 | 已停用→已生效 |
| TC-M08 到期 | 已生效 | 有效期止早于当前日 | 状态=已过期，不可引用 |
| TC-M09 导入部分失败 | 固定模板 | 上传 5 行，构造 1 行错误 | 成功4、失败1，成功行待审核 |
| TC-M10 AI 回写 | 分析任务已确认 | 回写资料 | AI 标记=true，状态=待审核 |
| TC-M11 未生效引用拦截 | 草稿/待审核资料 | 在选题生成页查找 | 不出现在选项中 |
| TC-M12 成员审核 | 成员在授权数据范围 | 打开审核队列并审核 | 按 SSOT 允许；当前前端为已知差异 |

## 二、状态快照

### 快照 1：新增与提交

```text
#101《制造业客户为什么不信代运营》
分类=商业研究结论  可信度=高
有效期=2026-08-24~2027-08-24
标签=[制造业, 获客]
保存后：草稿
提交后：待审核
```

### 快照 2：审核后

```text
#101 → 已生效，reviewer_id=管理员，reviewed_at 已写入
#102《未经核实的传闻》→ 已废弃
下游可见集合：仅 #101
```

### 快照 3：AI 回写

```text
#201《分析发现：咨询转化下降的三个原因》
is_ai_product=true
source_analysis_task_id=31
status=待审核
```

## 三、导入数据验证

## 四、走查清单

- [ ] M01-M08 对应验收项均可映射到页面动作
- [ ] 只有已生效资料可被下游引用
- [ ] 标签组可空，自由标签可即建即用
- [ ] 导入部分失败不回滚成功行
- [ ] AI 回写产物有标记、有来源、需再审核
- [ ] 资料审核成员权限实现差异已登记
- [ ] 未确认的资料版本表未进入一期
