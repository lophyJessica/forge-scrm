# 资料库_Demo_详情页

> 文件定位：资料列表内嵌详情 Modal 规格
> 实现来源：`frontend/src/pages/materials/MaterialList.tsx`
> 路由：无独立路由，由 `/materials` 点击标题打开

## 一、打开与关闭

- 点击列表标题，将当前行对象写入 `detail` 并打开 Modal。
- Modal 标题为资料标题，宽度 760，无底部按钮。
- 点击关闭或遮罩后清空 `detail`。

## 二、当前展示结构

```text
标题：资料标题
第一行：分类 / 状态 / 可信度
第二行：有效期起 ~ 有效期止
第三行：来源链接（有值时显示）
正文：保留换行展示
```

| 展示项 | 字段 | 空值行为 |
|---|---|---|
| 标题 | title | 不应为空 |
| 分类 | class_name | 当前无显式占位 |
| 状态 | status | 不应为空 |
| 可信度 | trust_level | 不应为空 |
| 有效期 | valid_from/valid_until | 不应为空 |
| 来源链接 | source_url | 为空时整行隐藏 |
| 正文 | content | 不应为空 |

## 三、交互边界

- Modal 只读，不在弹窗内审核、编辑或改变状态。
- 编辑从列表“编辑”按钮进入 `/materials/:id`。
- 来源链接当前直接使用 `<a href>`；是否新窗口打开未定义，不新增规则。

## 四、与字段口径的差异

当前详情 Modal 未展示标签、AI 产物标记、来源分析任务、审核人/时间、创建人/时间。这是现有页面范围，不代表字段不存在；开发扩展前应按产品优先级确认。

## 六、验收

- [ ] 点击标题打开对应资料，不串行
- [ ] 来源链接为空时不显示空链接行
- [ ] 正文换行保留，长内容可阅读
