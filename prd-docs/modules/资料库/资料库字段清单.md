# 资料库字段清单

> 文件定位：资料库字段 SSOT 展开版
> 权威：`context/05-术语与字段口径.md` §4.1/§4.2；类型映射参照 `prd-docs/核心字段清单.md` §1
> 规则：未在上述来源确认的字段统一标注“新增建议，待确认”

## 一、资料分类 material_class

| 字段 | 类型 | 必填 | 说明/确认度 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| name | varchar(50) | ✅ | 分类名，唯一 |
| parent_id | bigint | 否 | 可选父级分类 |
| sort | int | 否 | ⚠️ 新增建议，待确认：前端分类页已使用的排序字段 |
| created_at | datetime | ✅ | 数据库必要时间戳 |

确认分类枚举：商业研究结论、案例包装、评论和私信、个人观点、对标账号分析、相关热点。

## 二、资料条目 material

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| title | varchar(200) | ✅ | 标题 |
| content | longtext | ✅ | 正文 |
| class_id | bigint FK | ✅ | 所属分类 |
| source_type | enum | ✅ | 公众号/报告/社交/客户/思考/对标 |
| source_url | varchar(500) | 条件 | 视来源情况填写 |
| trust_level | enum | ✅ | 高/中/低 |
| valid_from | date | ✅ | 有效期起 |
| valid_until | date | ✅ | 有效期止 |
| status | enum | ✅ | 草稿/待审核/已生效/已停用/已过期/已废弃 |
| is_ai_product | bool | ✅ | AI 分析回写为 true |
| source_analysis_task_id | bigint FK | 条件 | AI 回写时关联来源任务 |
| reviewer_id | bigint FK | 条件 | 审核人 |
| reviewed_at | datetime | 条件 | 审核时间 |
| created_by | bigint FK | ✅ | 创建人 |
| created_at | datetime | ✅ | 创建时间 |

索引：`class_id`、`status`、`valid_until`、标题全文索引。

## 三、标签 tag

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| name | varchar(50) | ✅ | 标签名，唯一 |
| group_name | varchar(50) | 否 | 可选标签组，不强制分组（D1） |
| created_by | bigint FK | 否 | 数据库技术映射：创建人 |
| created_at | datetime | ✅ | 创建时间 |

## 四、资料-标签关联 material_tag

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| material_id | bigint FK | ✅ | 资料 id |
| tag_id | bigint FK | ✅ | 标签 id |

唯一约束：`(material_id, tag_id)`。

## 五、页面展示与查询映射

| 页面用途 | 字段 |
|---|---|
| 列表主列 | id/title/is_ai_product/class_name/tags |
| 质量信息 | source_type/trust_level/valid_from/valid_until/status |
| 查询条件 | keyword/class_id/tag/status |
| 详情弹窗 | title/content/class_name/status/trust_level/valid_from/valid_until/source_url |

`class_name`、导入成功/失败计数、导入错误行和原文件路径属于接口展示 DTO，不是新增业务表字段。若固化为业务字段，需先回写 SSOT；当前统一视为技术返回值。
