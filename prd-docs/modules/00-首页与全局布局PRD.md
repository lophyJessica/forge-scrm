# 首页与全局布局PRD

> 文件定位：登录后默认页（首页）+ 全局布局规范（菜单/导航）
> 确认：2026-08-24 用户确认首页方向；菜单默认折叠为全局默认
> 配套：全模块 Demo 页共用本规范

## 1. 页面概述

```text
路由：/（根路径）→ 首页
登录后默认落地页：首页（不是最后一个停留页，也不是某模块列表）
作用：全局概览 + 快捷入口 + 待办提醒
```

## 2. 全局布局规范

### 2.1 布局结构

```text
┌─────────────────────────────────────────────────┐
│ 侧边栏（默认折叠）  │  顶栏                     │
│                   │  面包屑/标题  登录人 ▼      │
│  （菜单图标列）     │                            │
│                   │                          │
│                   │  内容区（当前页面）          │
│                   │                          │
└─────────────────────────────────────────────────┘
```

### 2.2 侧边栏（菜单）

| 项 | 规格 |
|---|---|
| 默认状态 | **折叠**（只显示图标，鼠标展开） |
| 展开宽度 | 220px |
| 折叠宽度 | 64px（仅图标） |
| 切换 | 顶栏汉堡按钮，可展开/收起 |
| 记忆 | 用户展开/折叠状态 localStorage 记忆（刷新不丢） |

### 2.3 菜单项定义

```text
首页（默认选中）
资料库
选题库
脚本库
数据分析
权限管理（仅管理员可见）
```

菜单权限：普通成员不显示"权限管理"。

### 2.4 顶栏

```text
左：汉堡按钮（展开/收起侧边栏）+ 面包屑（如：首页 / 选题库）
右：登录人姓名 + 角色 Tag + 下拉（修改密码/退出登录）
```

## 3. 首页内容（2026-08-24 确认方向）

### 3.1 结构（从上到下）

```text
┌──────────────────────────────────────────────────┐
│ 欢迎回来，操盘手（管理员）                           │
│                                                  │
│ [数据概览卡片 × 4]                                │
│  资料总数 │ 选题总数 │ 脚本总数 │ 分析任务数        │
│  (12)    │ (45)    │ (18)    │ (6)              │
│                                                  │
│ [快捷入口 × 4]                                    │
│  去生成选题 │ 去生成脚本 │ 导入资料 │ 新建分析       │
│                                                  │
│ [待办提醒]                                        │
│  待审核资料 3 条 → 点击跳资料库                   │
│  待筛选选题 12 条 → 点击跳选题库                   │
│  待审核脚本 2 条 → 点击跳脚本库                   │
│                                                  │
│ [最近动态列表]                                    │
│  10:30 生成选题批次 T20260824-001（9 条）          │
│  10:15 脚本《代运营值不值》已通过审核              │
│  09:50 导入资料 5 条                              │
└──────────────────────────────────────────────────┘
```

### 3.2 数据概览卡片（4 个）

| 卡片 | 数据来源 | 说明 |
|---|---|---|
| 资料总数 | /api/materials 计数 | 显示总数 + "已生效 X"小字 |
| 选题总数 | /api/topics 计数 | 显示总数 + "待筛选 X"小字 |
| 脚本总数 | /api/scripts 计数 | 显示总数 + "已通过 X"小字 |
| 分析任务数 | /api/analysis-tasks 计数 | 显示总数 + "待审核 X"小字 |

点击卡片可跳对应模块列表（可选，二期）。

### 3.3 快捷入口（4 个按钮）

| 按钮 | 跳转 |
|---|---|
| 去生成选题 | /topics/generate |
| 去生成脚本 | /scripts/generate |
| 导入资料 | /materials/import |
| 新建分析 | /analysis/new |

主按钮样式（首按钮 primary，其余 default）。

### 3.4 待办提醒

| 项 | 数据 | 交互 |
|---|---|---|
| 待审核资料 | status=待审核 计数 | 整行可点击 → 跳资料库并带筛选 |
| 待筛选选题 | status=待筛选 计数 | 跳选题库（Tab=待筛选） |
| 待审核脚本 | status=待审核 计数 | 跳脚本库（Tab=待审核） |

无待办时显示"暂无待办，去生成一批选题吧"。

### 3.5 最近动态列表

```text
来源：合并最近操作（生成选题/脚本审核/资料导入/分析完成）
显示：最近 5 条，时间倒序，每条 = 图标 + 描述 + 时间
每条可点击跳对应详情（二期），一期纯展示
```

## 4. 权限

| 内容 | 管理员 | 普通成员 |
|---|---|---|
| 首页全部内容 | ✅ | ✅ |
| 快捷入口"导入资料"/"新建分析" | ✅ | ✅（成员也允许导入/分析，与权限矩阵一致） |
| 权限管理菜单 | ✅ | ❌（菜单直接隐藏） |

数据概览卡片成员可见但只读展示自己的数据范围（二期数据隔离，一期全量）。

## 5. 空态与异常

- 无数据：卡片显示 0，待办显示"暂无待办"
- 接口失败：卡片显示"--"，不影响其他区域
- 刷新：手动刷新按钮（右上角）或 15s 自动刷新（一期手动即可）

## 6. 验收标准

- [ ] 登录后默认进入首页
- [ ] 侧边栏默认折叠，汉堡可展开，状态记忆
- [ ] 4 个数据卡片加载正确
- [ ] 4 个快捷入口跳转正确
- [ ] 待办提醒计数正确，点击跳转带筛选
- [ ] 最近动态显示最近 5 条
- [ ] 普通成员登录不显示"权限管理"菜单
- [ ] 首页刷新/空态正常
