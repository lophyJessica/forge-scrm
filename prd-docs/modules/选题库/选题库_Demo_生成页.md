# 选题库_Demo_生成页

> 文件定位：选题生成页 Demo 规格——含业务方向/专业方向即建即用 + 二级联动
> 配套：选题库主PRD.md / 选题库_业务规则规格.md / 选题库字段清单.md / 选题库_Demo_列表页.md

## 一、页面概述

```text
路由：/topics/generate（或列表页右上角"批量生成"弹窗）
用途：选择/新增方向 → 填参数 → 调 AI 批量生成选题
访问权限：管理员/普通成员
```

## 二、页面结构（从上到下）

```text
┌─────────────────────────────────────────────────┐
│ 标题：批量生成选题                                │

│ *业务方向   [下拉 Select（可搜索+可新增）] ▼      │

│  参考资料   [下拉多选（仅已生效资料）] ▼          │
│  提示词模板 [下拉单选（可选，不选用内置）] ▼       │
│                                                │
│        [取消]        [开始生成]（主按钮）         │
└─────────────────────────────────────────────────┘
```

## 三、业务方向 Select（即建即用）

### 3.1 常态

- 选项来源：GET /api/directions → 业务方向列表
- 可搜索（filterOption 按 name 匹配）
- **必填**：未选择时点"开始生成"提示"请选择或新增业务方向"

### 3.2 "+ 新增业务方向"入口

- 位置：下拉底部固定项"+ 新增业务方向"
- 交互：点击 → 下拉内嵌输入框（或 Modal）
- 提交流程：
  1. 输入名称 → 回车/[确定]
  2. POST /api/directions/business
  3. 成功 → 下拉刷新，新方向自动选中
  4. 重名 → 报错"该业务方向已存在"，输入框保留
  5. 空值/超长 → 提示"请输入 1-50 字符"

### 3.3 交互细节

```text
当你输入"企业服务获客"且不存在 → 下拉尾显示"+ 新增"企业服务获客""（快捷直达）
点击后直接提交该名称，省一步
```

## 四、专业方向 Select（二级联动 + 即建即用）

### 4.1 联动规则

| 状态 | 行为 |
|---|---|
| 未选业务方向 | 下拉**禁用**，placeholder="请先选择业务方向" |
| 已选业务方向 | 下拉启用，选项=该业务方向下的专业方向（GET /api/directions 过滤） |
| 切换业务方向 | 已选专业方向**清空**，选项刷新 |

### 4.2 可空

专业方向**非必填**（可只填业务方向生成），但如有值必须属于当前业务方向。

### 4.3 "+ 新增专业方向"入口

- 仅当**已选业务方向**时可点（未选时禁用）
- 点击 → 输入名称 → POST /api/directions/specialties {business_direction_id, name}
- 成功 → 刷新并自动选中
- 组内重名 → 报错"该专业方向已存在"

## 五、生成条数

- 数字输入，默认 10，范围 1-10
- 越界时失焦校验提示

## 六、参考资料（多选）

- 数据源：/api/materials?status=已生效（仅已生效可勾选）
- 可空（"可不选"占位）
- 选中后显示名称 Tag，可移除
- 参与提示词拼接（取标题+摘要，截断保护）

## 七、提示词模板（单选）

- 数据源：/api/prompts（task_type=选题生成）
- 可空（默认内置模板，占位"不选用内置模板"）
- 选中后替代内置模板

## 八、开始生成（主交互）

```text
前置校验：
1. 业务方向必填
2. 条数 1-10
3. 后端校验：专业方向属于所选业务方向（若有）

点击后：
1. 按钮 loading + 防重入（isOperating）
2. POST /api/topics/generate
3. 成功：提示"生成成功 N 条（重复 X 条已跳过）"→ 跳转列表页（Tab=待筛选）
4. 失败：报错提示（超时/格式错误），按钮恢复可点
```
