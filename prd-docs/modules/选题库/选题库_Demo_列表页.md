# 选题库_Demo_列表页

> 文件定位：选题库列表页 Demo 规格（页面结构、控件、交互、Mock）
> 配套：选题库主PRD.md / 选题库_业务规则规格.md / 选题库字段清单.md

## 一、页面概述

```text
路由：/topics
用途：选题列表 + 状态 Tab + 筛选 + 行内操作（选定/废弃/编辑）
访问权限：管理员/普通成员（删除仅管理员）
```

## 二、状态 Tab 栏

### 2.1 Tab 项定义

| Tab | 筛选条件 | 说明 |
|---|---|---|
| 全部（默认） | 无 | 显示所有状态 |
| 待筛选 | status=待筛选 | AI 生成未处理 |
| 已选定 | status=已选定 | 可用选题 |
| 已废弃 | status=已废弃 | 不可用 |

### 2.2 计数规格

每个 Tab 后显示数量徽标（如 `待筛选 (12)`），数量实时刷新。

### 2.3 交互行为

- 默认落在"全部"；点击 Tab 切换筛选
- 切换 Tab 重置分页到第 1 页

## 三、查询区

### 3.1 布局说明

一行查询表单：业务方向下拉 + 状态下拉 + 关键词输入 + [搜索] [重置]

### 3.2 查询条件

| 条件 | 控件 | 说明 |
|---|---|---|
| 业务方向 | Select（可搜索） | 从 /api/directions 加载，含"全部"选项 |
| 状态 | Select | 全部/待筛选/已选定/已废弃 |
| 关键词 | Input | 标题/角度模糊搜索 |
| 批次号 | Input（可选） | 精确/模糊匹配 batch_no |

按钮：[搜索] 触发查询；[重置] 清空条件回默认

## 四、工具条（表格上方右侧）

| 按钮 | 动作 | 权限 |
|---|---|---|
| [批量生成] | 打开生成页（路由 /topics/generate 或弹窗） | 管理员/成员 |
| [导出 CSV]（希望有） | 导出当前筛选结果 | 管理员/成员 |

## 五、表格

### 5.1 表格行为

- 分页：每页 20 条，服务端分页
- 排序：默认按 created_at 倒序
- 行选中：无多选（一期不做批量操作）

### 5.2 列定义（从左到右）

| 列 | 数据字段 | 宽度 | 说明 |
|---|---|---|---|
| 选题标题 | title | 自适应 | 主列，可点击进详情（二期）；含 angle 副标题 |
| 业务方向 | direction | 120 | Tag 或纯文本 |
| 专业方向 | specialty | 120 | Tag 或纯文本 |
| 批次号 | batch_no | 140 | 生成批次 |
| 状态 | status | 100 | 状态 Tag（见 5.3） |
| 生成时间 | created_at | 160 | YYYY-MM-DD HH:mm |
| 操作 | — | 200 | 行内按钮（见 5.4） |

### 5.3 状态 Tag 配色

| 状态 | 颜色 |
|---|---|
| 待筛选 | orange |
| 已选定 | blue |
| 已废弃 | gray（划线） |
| 已生成脚本 | green |
| 已使用 | purple |

### 5.4 行内操作

| 状态 | 操作按钮 | 行为 |
|---|---|---|
| 待筛选 | [选定] [废弃] [编辑] | 选定→确认后变已选定；废弃→Popconfirm"废弃后不可恢复" |
| 已选定 | [废弃] [编辑] | 允许改判废弃 |
| 已废弃 | [删除]（管理员）| 物理删除（仅管理员） |
| 已生成脚本/已使用 | 无操作 | 保护下游，不可改 |

## 六、空态与加载

- 无数据：空状态插画 + "暂无选题，点击右上角[批量生成]开始"
- 加载中：Table loading 态
- 生成失败：提示条"生成失败，请重试"（详情见生成页）
