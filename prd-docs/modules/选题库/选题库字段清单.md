# 选题库字段清单

> 文件定位：选题库字段唯一定义（SSOT 展开版）
> 权威：字段口径以 context/05 为唯一事实源；本文件是选题库展开，不重复定义其他模块字段
> 配套：选题库主PRD.md / 选题库_业务规则规格.md

## 一、业务方向表（business_direction）— 新增建议，待确认

> 说明：一级分类。2026-08-24 确认"即建即用"。context/05 未定义此表，标注"新增建议"。

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| id | bigint PK | ✅ | 自增 |
| name | varchar(50) | ✅ | 业务方向名称，唯一 |
| status | enum | ✅ | active / inactive（一期只做新增，不做停用，预留） |
| created_by | bigint FK | ✅ | 创建人（user.id） |
| created_at | datetime | ✅ | 创建时间 |

## 二、专业方向表（specialty）— 新增建议，待确认

> 说明：二级分类，挂业务方向下。2026-08-24 确认"二级联动 + 即建即用"。

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| id | bigint PK | ✅ | 自增 |
| business_direction_id | bigint FK | ✅ | 所属业务方向 id |
| name | varchar(50) | ✅ | 专业方向名称，**组内唯一**（同业务方向下不可重名） |
| status | enum | ✅ | active / inactive |
| created_by | bigint FK | ✅ | 创建人 |
| created_at | datetime | ✅ | 创建时间 |

唯一约束：`(business_direction_id, name)` 联合唯一。

## 三、选题表（topic）

### 3.1 新增页字段（生成/手动新增）

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| batch_no | varchar(32) | ✅ | 生成批次号（每次生成一批一个号，如 T20260824-001） |
| direction | varchar(50) | ✅ | 业务方向名称（字符串列，兼容现状；读取时关联 business_direction.name） |
| specialty | varchar(50) | ✅ | 专业方向名称（字符串列，兼容现状；读取时关联 specialty.name） |
| title | varchar(200) | ✅ | 选题标题 |
| angle | varchar(200) | ❌ | 切入角度（AI 生成或人工补充） |
| reference_materials | text | ❌ | 参考资料摘要（生成时拼接的上下文快照，可选） |
| prompt_version_snapshot | text | ❌ | 提示词快照（内置模板或选中模板内容，追溯可选） |
| ai_raw_response | json/text | ❌ | AI 原始响应留档（S04 验收） |

### 3.2 列表页展示字段

| 字段 | 说明 |
|---|---|
| id | 选题 id |
| batch_no | 批次号 |
| direction | 业务方向 |
| specialty | 专业方向 |
| title | 标题 |
| angle | 切入角度 |
| status | 状态 Tag（待筛选/已选定/已废弃/已生成脚本/已使用） |
| created_at | 生成时间 |
| creator | 创建人 |

### 3.3 筛选条件

| 条件 | 说明 |
|---|---|
| status | 状态筛选（全部/待筛选/已选定/已废弃） |
| direction | 业务方向筛选 |
| batch_no | 批次号筛选 |
| keyword | 标题/角度关键词模糊搜索 |

### 3.4 系统字段

| 字段 | 说明 |
|---|---|
| id | PK |
| status | 见状态机（默认待筛选） |
| screening_result | 筛选结果（派生：selected / discarded），由动作按钮写入 |
| created_at / updated_at | 时间戳 |
| created_by | 创建人（生成人） |

## 四、与核心字段清单的差异说明

| 项 | 核心字段清单（原） | 本文件（更新后） | 说明 |
|---|---|---|---|
| 专业方向 | specialty 枚举（Specialty 类） | 专业方向表（id 关联，name 冗余入 topic） | 2026-08-24 确认即建即用，枚举→表 |
| 业务方向 | direction 自由字符串 | 业务方向表（name 唯一）+ topic.direction 冗余 | 新增方向表，topic 结构不变 |

> 实现说明：为最小改动，topic 表结构保持不变（direction/specialty 字符串列），方向管理独立建表；生成时按名称写入 topic 行，同时方向下拉从方向表读取。
