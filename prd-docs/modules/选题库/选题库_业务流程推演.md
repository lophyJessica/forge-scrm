# 选题库_业务流程推演

> 文件定位：选题库动态沙盘——分步推演 + 真实示例数据，验证流程可走通
> 配套：选题库主PRD.md / 选题库_业务规则规格.md / 选题库_用例数据推演.md

## 一、主流程推演（日常批量薅选题）

### 步骤 1：进入选题库 → 打开生成页

```text
入口：登录 → 左侧菜单"选题库" → 右上角"批量生成"按钮
```

示例数据：

```text
当前登录人：姐夫（管理员）
现有业务方向：制造业获客、服务业增长、招商加盟
现有专业方向（制造业获客下）：短视频获客、直播获客、展会获客
```

### 步骤 2：选择/新增业务方向

```text
操作：业务方向下拉 → 选项"制造业获客"
（如果没有想要的 → "+ 新增业务方向" → 输入"企业服务获客" → 提交 → 自动选中）
```

推演（即建即用）：

```text
姐夫想要"企业服务获客"但库里没有：
1. 点"+ 新增业务方向"
2. 输入"企业服务获客"
3. 提交 → POST /api/directions/business → 成功
4. 下拉刷新，新方向出现在列表中并自动选中
5. 关联校验：无重名冲突
```

### 步骤 3：选择专业方向（二级联动）

```text
操作：专业方向下拉 → 只显示"企业服务获客"下的方向（空）
→ "+ 新增专业方向" → 输入"账号代运营获客" → 提交 → 自动选中
```

推演（联动）：

```text
1. 未选业务方向时：专业方向下拉禁用，提示"请先选择业务方向" ✅
2. 选中"企业服务获客"后：专业方向下拉可用，选项=该业务方向下的专业方向 ✅
3. 新增"账号代运营获客"（挂企业服务获客下）→ 自动选中 ✅
4. 若切换业务方向回"制造业获客" → 专业方向清空重置 → 选项变为 短视频/直播/展会获客 ✅
```

### 步骤 4：填生成参数

```text
生成条数：10（默认）
参考资料：勾选 2 条已生效资料（如"企业代运营痛点总结"、"客户评论分析"）
提示词模板：不选（用内置模板）
```

### 步骤 5：点击"开始生成"

```text
前端：按钮 loading，防重复点击
后端：POST /api/topics/generate
  ├─ 组装提示词（业务方向+专业方向+参考资料摘要+输出格式要求）
  ├─ 调 DeepSeek（超时 120s，失败重试 3 次）
  ├─ 解析 JSON → 10 条选题
  ├─ 完全重复去重（对全表历史 + 本批）
  ├─ 入库：batch_no=T20260824-001，status=待筛选，ai_raw_response 留档
  └─ 返回：生成成功 10 条（重复 0 条跳过）
```

### 步骤 6：人工筛选

```text
操作：列表逐条判断 → 5 条点"选定"、3 条点"废弃"、2 条改标题后"选定"
```

推演（筛选）：

```text
批量生成返回 10 条，展示在"待筛选"Tab：
├─ 第1条 "企业代运营到底值不值" → 选定
├─ 第2条 "代运营公司怎么选不踩坑" → 选定
├─ 第3条（与历史完全重复"如何低成本获客"）→ 已被去重，不出现
├─ 第4条 "老板要不要亲自管账号" → 选定
├─ 第5条 "代运营合同避坑指南" → 选定
├─ 第6条 "代运营报价怎么看" → 编辑标题为"代运营报价拆解"→ 选定
├─ 第7条 "短视频没人看的原因" → 废弃
├─ 第8条 "直播带货失败案例" → 废弃
├─ 第9条 "企业号冷启动方法" → 选定
└─ 第10条 "（AI 生成的质量差）" → 废弃

结果：待筛选 0 / 已选定 7 / 已废弃 3
```

### 步骤 7：进入脚本生成（下游）

```text
已选定选题进入脚本库生成候选
选题状态由脚本库动作派生：已选定 → 已生成脚本 → 已使用
（详见脚本库套件）
```

## 二、边界场景推演

### 场景 A：AI 超时/失败

```text
第 1 次调用：超时 120s → 重试（退避 2s）
第 2 次调用：返回 500 → 重试（退避 4s）
第 3 次调用：成功 → 返回 10 条
结果：正常生成；若 3 次全失败 → 前端提示"生成失败，请重试"，无脏数据
```

### 场景 B：AI 返回重复

```text
AI 返回 10 条，其中 2 条与历史完全重复、1 条本批内重复
去重后：入库 7 条，返回提示"3 条重复已跳过"
```

### 场景 C：专业方向重名

```text
"企业服务获客"下已有"账号代运营获客"
再次新增同名 → 拒绝，提示"该专业方向已存在"
```
