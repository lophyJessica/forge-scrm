# 数据分析_业务流程推演

> 文件定位：数据准备→任务执行→审核→回写/反哺的沙盘推演

## 一、主流程

```text
登记数据源
→ 手动录入或 CSV/TXT 导入原始数据
→ 选择一组原始数据
→ 可选已生效资料上下文和提示词模板
→ 创建任务（待执行）
→ 同步执行（执行中）
→ 输出校验
├─ 成功：已完成→待审核
└─ 失败：失败→重新执行
→ 人工确认
├─ 已确认→回写资料库（待审核 AI 资料）
└─ 已确认→反哺选题（待筛选选题）
```

## 二、数据准备流程

```text
数据源：视频号-自己 / 视频号-对标 / 报告文本
采集方式：手动录入或 CSV 导入
业务对象：账号指标或内容资料
平台：视频号或文本资料为空
→ 原始数据保留 raw_content、structured、时间窗
```

一期不实际运行自动采集；未来启用时按人工触发、不做定时规则扩展。

## 三、失败重试推演

```text
第1次：DeepSeek 超时 → 失败，记录错误，保留响应
点击重新执行 → 执行中
成功 → 已完成 → 待审核
全部失败 → 仍为失败，允许后续再次执行
```

## 四、双回写独立性

```text
结果 #501 已确认
├─ 回写资料库 → material status=待审核，writeback_material_status=已回写
└─ 反哺选题库 → topic status=待筛选，writeback_topic_status=已反哺

只完成其中一个动作时，另一个状态保持未回写/未反哺。
```

## 五、边界场景

### 场景 A：混合导入

```text
CSV 10 行：成功8、失败2
成功8条进入原始数据，失败2条展示行号和原因
任务选择器只列入库成功的8条
```

### 场景 B：未审核拦截

```text
任务=待审核
点击回写/反哺 → 按钮置灰或 API 拒绝
状态不发生变化
```
