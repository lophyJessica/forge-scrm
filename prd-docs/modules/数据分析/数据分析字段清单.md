# 数据分析字段清单

> 文件定位：数据分析字段 SSOT 展开版
> 权威：`context/05-术语与字段口径.md` §4.6/§4.7；类型映射参照 `prd-docs/核心字段清单.md` §4

## 一、数据源 data_source

| 字段 | 类型 | 必填 | 说明/确认度 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| name | varchar(100) | ✅ | 数据源名称 |
| collection_method | enum | ✅ | 手动录入/CSV 导入；自动采集仅架构预留 |
| business_object | enum | ✅ | 自己账号/对标账号/行业报告/相关热点/评论和私信 |
| platform | enum | 条件 | 视频号；非平台文本资料可为空 |
| account_identifier | varchar(200) | 条件 | 账号类数据必填 |
| is_benchmark | bool | ✅ | 是否对标账号 |
| config | json | 否 | ⚠️ 新增建议，待确认：API/OAuth/调度配置 |
| status | enum | 否 | ⚠️ 新增建议，待确认：启用/停用 |

## 二、原始数据 raw_data

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| source_id | bigint FK | ✅ | 数据源 |
| collected_at | datetime | ✅ | 原始数据获取时间 |
| raw_content | longtext | 否 | 原始内容或对象存储引用 |
| structured | json | 否 | 通用基础结构；一期不固化深度指标 |
| window_start | datetime | ✅ | 统计时间窗起 |
| window_end | datetime | ✅ | 统计时间窗止 |
| clean_dedup_record | json | ✅ | 清洗/去重记录 |

## 三、分析任务 analysis_task

| 字段 | 类型 | 必填 | 说明/确认度 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| name | varchar(100) | 否 | ⚠️ 新增建议，待确认；前端允许留空 |
| type | enum | ✅ | 指定分析任务类型 |
| prompt_version_snapshot | json | 否 | 可选提示词快照 |
| material_context_snapshot | json | 否 | 可选资料上下文快照 |
| output_schema | json | ✅ | 输出字段定义 |
| ai_raw_response | longtext | ✅ | AI 原始响应留档 |
| status | enum | ✅ | 待执行/执行中/已完成/失败/待审核/已确认/已废弃 |
| reviewer_id | bigint FK | 条件 | 审核人 |
| reviewed_at | datetime | 条件 | 审核时间 |
| created_by | bigint FK | ✅ | 创建人 |
| created_at | datetime | ✅ | 创建时间 |
| retry_count | int | 否 | ⚠️ 新增建议，待确认；前端展示重试次数 |

## 四、分析任务输入 analysis_task_input

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| task_id | bigint FK | ✅ | 任务 |
| raw_data_id | bigint FK | ✅ | 原始数据；与 task_id 组成唯一关系 |

## 五、分析结果 analysis_result

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| task_id | bigint FK | ✅ | 任务 |
| result_content | json | ✅ | 通用结构化结果：效果/结论/建议等 |
| writeback_material_status | enum | ✅ | 未回写/已回写 |
| writeback_topic_status | enum | ✅ | 未反哺/已反哺 |

## 六、回写关联

### analysis_result_material

`id`、`result_id`、`material_id`，均为必填技术字段；表示结果回写生成的资料集合。

### analysis_result_topic

`id`、`result_id`、`topic_id`，均为必填技术字段；表示结果反哺生成的选题集合。

## 七、页面 DTO 映射

| 页面 | 主要字段 |
|---|---|
| 数据源 | id/name/collection_method/business_object/platform/account_identifier/is_benchmark/status |
| 原始数据 | id/source_name/raw_content/collected_at/window_start/window_end/structured |
| 任务列表 | id/name/type/status/retry_count/created_at |
| 任务详情 | 输入数据、提示词快照、资料快照、结果、回写状态、错误信息 |
| 导入结果 | total/success/failed/errors/stored_file（接口返回 DTO） |

## 八、分析结果通用 schema

前端当前读取 `effect`、`conclusion`、`suggestions`、`evidence`、`material_candidates`、`topic_candidates`。这些是结果 JSON 的当前展示约定，不新增为固定业务列；深度指标仍属于二期。
