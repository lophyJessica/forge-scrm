# 数据分析_Demo_数据准备与提示词页

> 文件定位：数据源、原始数据、提示词模板三个实际页面的合并规格
> 覆盖实现：DataSources.tsx / RawData.tsx / PromptTemplates.tsx

## 一、数据源管理 `/analysis/data-sources`

### 列表

ID、名称、采集方式、业务对象、平台、账号标识、对标账号、状态、操作。管理员显示新增/编辑/删除；页面 Alert 明确一期不执行自动采集。

### Modal

名称、采集方式、业务对象、平台、账号标识、是否对标账号、状态。默认手动录入、非对标、启用。

> `status` 与 DataSources 页的启停按钮属于当前实现字段，在 context/05 标为新增建议、待确认。

## 二、原始数据 `/analysis/raw-data`

### 数据列表 Tab

按数据源筛选，服务端分页 20；列 ID、数据源、原始内容摘要、采集时间、时间窗起止、编辑/删除；展开行展示原始内容和结构化 JSON。

### CSV 导入 Tab

下载模板、上传 CSV/TXT，结果显示总数/成功/失败/原文件路径和失败行表格。

### 手动录入 Modal

数据源、原始内容、统计时间窗、采集时间（可留空取当前时间）、结构化字段 JSON。编辑时数据源禁用；非法 JSON 阻止保存。

## 三、提示词模板 `/analysis/prompts`

- 查询：任务类型、状态。
- 表格：ID、名称、任务类型、版本、状态、创建时间、查看/编辑/删除。
- 新增/编辑 Modal：任务类型、模板名称、提示词正文、输出字段定义 JSON、状态。
- 分析类模板要求输出字段定义；正文修改时版本号由后端递增，独立版本表不在一期建立。
- 详情 Modal 只读展示正文和输出 schema。

## 五、实现差异

- DataSources 允许编辑/删除的管理员边界与成员矩阵需后端复核。
- RawData 页面实际上传按钮文案为“上传 CSV”，但 accept 同时包含 `.csv,.txt`；文档按实现行为记录。
- PromptTemplates 页面有版本号展示，但版本字段在 context/05 仍为新增建议、待确认。
