# 数据分析_用例数据推演

> 文件定位：数据分析用例、状态快照和回写走查

## 一、核心用例表

| 用例 | 前置 | 操作 | 期望结果 |
|---|---|---|---|
| TC-A01 新建数据源 | 管理员 | 填名称/采集方式/对象 | 数据源保存 |
| TC-A02 手动录入 | 有数据源 | 填原始内容、时间窗 | raw_data 入库 |
| TC-A03 CSV 导入 | 固定模板 | 上传 5 行 | 成功/失败计数，原文件留档 |
| TC-A04 非法 JSON | 手动录入 | structured 填非法 JSON | 阻止保存并提示 |
| TC-A05 创建任务 | 有原始数据 | 选输入/资料/模板 | 任务=待执行 |
| TC-A06 执行成功 | 待执行 | 点执行 | 执行中→已完成→待审核 |
| TC-A07 执行失败重试 | 待执行 | 模拟失败后重试 | 失败→执行中，保留错误 |
| TC-A08 审核确认 | 待审核 | 点确认结果 | 状态=已确认 |
| TC-A09 审核驳回 | 待审核 | 点驳回 | 状态=已废弃 |
| TC-A10 未审核拦截 | 待审核 | 点回写/反哺 | 操作被阻止 |
| TC-A11 回写资料 | 已确认 | 编辑候选并提交 | AI资料待审核，动作状态已回写 |
| TC-A12 反哺选题 | 已确认 | 编辑候选并提交 | 选题待筛选，动作状态已反哺 |
| TC-A13 独立回写 | 已确认，资料已回写 | 再反哺 | 反哺按钮仍可用 |
| TC-A14 成员权限 | 成员无执行权限 | 打开任务页 | 不显示/拒绝执行动作 |

## 二、状态快照

```text
数据源 #11：手动录入 / 自己账号 / 视频号
原始数据 #201/#202：时间窗 2026-08-01~2026-08-23
任务 #501：待执行
```

```text
执行后：任务 #501=待审核
结果 #701：资料回写=未回写，选题反哺=未反哺
确认后：任务 #501=已确认
回写资料后：资料状态=待审核，资料回写=已回写
反哺选题后：选题状态=待筛选，选题反哺=已反哺
```

## 三、走查清单

- [ ] 手动录入/导入成功和失败行行为正确
- [ ] 任务输入为多条原始数据集合
- [ ] 资料上下文只取已生效
- [ ] 失败可重试且原始响应留档
- [ ] 未审核不可回写/反哺
- [ ] 两个回写动作状态独立
- [ ] 基础 JSON 输出不固化深度指标
- [ ] 待确认字段未作为阻塞验收条件
