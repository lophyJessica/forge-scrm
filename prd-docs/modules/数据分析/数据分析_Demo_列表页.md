# 数据分析_Demo_列表页

> 文件定位：现有 `AnalysisTasks.tsx` 页面规格
> 路由：`/analysis/tasks`

## 一、页面结构

```text
Card：分析任务
├─ 说明 Alert：一期同步执行，失败自动重试
├─ 右上：[新建分析任务]
├─ 查询：任务类型 / 状态 / 查询
└─ 表格：ID、任务名称、类型、状态、重试次数、创建时间、详情/执行/删除
```

## 二、实际交互

- 列表 GET `/analysis-tasks`，服务端分页 20。
- 点击任务名称或详情进入 `/analysis/tasks/:id`。
- 待执行显示“执行”，失败显示“重新执行”；权限由 `PERM.分析任务执行` 控制。
- 管理员显示删除 Popconfirm。
- 新建按钮由 `PERM.分析任务执行` 控制。

## 三、状态颜色

待执行 default、执行中 processing、已完成 blue、待审核 orange、已确认 green、失败 red、已废弃 default。
