# 研究助手_业务规则规格

> 文件定位：研究助手模块检索、长任务、报告、引用和内容生成规则
> 依据：`context/04-业务规则与状态机.md`、`context/05-术语与字段口径.md`、`requirements/09-二期调研结论.md`
> 规则约定：一期沿用 `R1-R20`；本模块新增规则使用 `RS-R` 前缀。新增实体、字段、状态、枚举和配置均为“新增建议，待确认”。

## 二、一期规则依赖

### 2.1 R1/R2：资料沉淀

报告沉淀资料库时，目标资料仍使用一期资料条目的标题、内容、资料分类、来源类型、来源链接、可信度、有效期、状态和创建追踪字段。报告是 AI 整理产物，目标资料必须保留 `is_ai_product=true` 语义。R2 的有效期和可信度不能因报告来自模型而省略；若默认通过直接设为可用，其状态映射仍需遵循二期审核说明并标注待确认。

### 2.2 R4/R14：报告生成选题

研究报告作为资料上下文生成选题时，选题继续保留生成批次和历史，并在入库前按标题完全重复去重。语义去重不在本模块强制实现。报告和引用可以作为可选追溯上下文，但不得被去重逻辑误当作新状态。

### 2.3 R5/R9/R10：报告生成脚本

1. 基于选题生成脚本时，必须展示并写入关联选题。
2. 每个选题生成 2-3 版脚本，沿用 R5。
3. 独立创建脚本时选题允许为空，但页面必须明确“独立创建”，并保留研究报告关联；沿用 R9/R10。
4. 脚本正式状态、审核和版本历史沿用一期；报告关联字段为新增建议，待确认。

### 2.4 R8：原始事实与 AI 产物

外部检索返回内容、自动采集结果和一期资料是来源事实或原始数据；研究报告、摘要、结论、选题和脚本若由模型生成，均属于 AI 产物。AI 产物不能覆盖来源内容，必须通过 `is_ai_product=true` 或等价标识区分，并保留输入/引用/生成追溯。二期默认通过放宽使用前审核，不取消事实与产物区分。

## 三、研究任务与阶段规则

### RS-R1 任务创建

1. 主题和研究目标必填；研究范围和时间窗按产品输入规则校验。
2. 创建任务后初始为待执行，不隐式启动联网调用。
3. 用户点击开始研究后，任务进入检索中。
4. 任务编号、创建时间、发起人和输入配置需可查询；最终字段均为新增建议，待确认。

### RS-R2 阶段进度和可恢复

研究任务至少需要让用户知道：

| 阶段 | 用户可见信息 | 失败后的动作 |
|---|---|---|
| 待执行 | 输入摘要、范围和开始按钮 | 开始或编辑未启动任务 |
| 检索中 | 已完成来源数、最近来源、最近更新时间 | 查看错误、重试 |
| 整理中 | 已整理章节/结论进度、最近更新时间 | 查看错误、重试 |
| 已完成 | 报告摘要、章节、引用和生成时间 | 查看、沉淀、生成 |
| 失败 | 失败阶段、错误信息和中间结果 | 重试或调整范围 |

`检索中`、`整理中`为新增建议，待确认；可使用一期“执行中”状态加 `current_stage` 字段表达。进度百分比、心跳、checkpoint、暂停和恢复位置均为新增建议，待确认。

### RS-R3 重试与恢复

1. 检索失败时允许重试，优先保留已有来源和错误。
2. 整理失败时允许重试，优先复用已保存检索结果，不要求重复访问所有来源；是否全量重检待确认。
3. 页面刷新、重新登录或浏览器关闭后，重新打开任务详情应读取服务端状态。
4. 重试动作不能清空已有报告草稿、引用关系或原始响应。
5. 重试上限、退避、手动确认和 checkpoint 数据格式为新增建议，待确认。

## 四、联网检索与合规规则

### RS-R4 检索源选择

检索源实现按实际可用性评估：DeepSeek 联网能力、Tavily 免费层或其他第三方检索 API 均是待实测候选，不将任一供应商写成已确认唯一依赖。候选源的成本、配额、稳定性、地域可用性、返回 URL、内容摘要和引用粒度都需测试。

### RS-R5 合规边界

| 检查项 | 规则 | 确认度 |
|---|---|---|
| robots | 遵守来源声明，禁止路径不访问 | 待实测/待确认 |
| 服务条款 | 不违反来源服务条款和平台规则 | 待实测/待确认 |
| 访问频率 | 控制请求频率和并发，不规避限制 | 待实测/待确认 |
| 版权 | 保留必要引用和来源，不默认复制受限全文 | 待实测/待确认 |
| 登录/验证码 | 不绕过登录、验证码、风控或付费墙 | 已确认边界 |
| 来源不可用 | 明确显示失败或缺失，不伪造引用 | 新增建议，待确认 |

检索结果应保存 URL、标题、检索时间、来源类型或供应商信息；字段名和保存范围为新增建议，待确认。

### RS-R6 来源质量

1. 来源响应为空、无 URL、无法解析或明确不可访问时，不作为完整引用。
2. 同一 URL 在一次研究任务中的重复结果应合并或标记重复；去重实现待确认。
3. 研究报告需区分来源事实、整理摘要和模型推断。
4. 若关键结论没有来源，报告中应显示未引用标记或待补证据提示；具体是否阻塞完成待确认。

## 五、报告与引用规则

### RS-R7 报告生成

报告至少包含摘要和正文；章节、结论、生成时间、任务关联和 AI 原始响应需可追溯。报告不把模型输出当作外部事实，`is_ai_product=true`。

### RS-R8 章节引用关系

1. 报告与外部 URL、第二步 `collection_result`、一期资料三类来源均可建立引用关系。
2. 引用关系至少记录报告、来源类型和来源目标；URL/采集结果/资料三者的具体互斥字段规则待确认。
3. 章节或结论引用若需要页码、段落、证据摘要和检索源类型，均为新增增强字段，待确认。
4. 点击引用时，外部 URL打开来源页面；采集结果或资料打开系统详情，并保留报告返回入口。
5. 来源被删除、停用或过期时，不删除报告原文；引用显示不可用状态和历史快照，具体策略待确认。

### RS-R9 报告可用性

报告整理完成且基本结构校验通过后进入已完成；是否将“缺少关键引用”作为硬失败待确认。整理失败不能标记已完成，已有检索来源仍可查看。

## 六、报告沉淀资料与内容生成规则

### RS-R10 沉淀资料库

1. 用户选择沉淀时，系统将报告映射到一期资料字段，不创建第二套资料口径。
2. 目标资料沿用 R2 的有效期和可信度，并保留来源类型/来源链接或引用关联。
3. 目标资料 `is_ai_product=true`，关联研究报告和引用；关联字段为新增建议，待确认。
4. 二期默认通过允许 AI 资料在不经过前置人工审核的情况下进入可用路径，但保留轻量抽查和原审核入口；状态映射待确认。
5. 报告沉淀动作幂等，重复点击不创建重复资料；幂等字段为新增建议，待确认。

### RS-R11 生成选题

1. 报告和其引用可作为资料上下文。
2. 选题生成沿用 R4/R14：保留历史，完全重复标题跳过或按一期规则提示。
3. 生成选题保留研究报告来源和 AI 原始响应；报告关联字段为新增建议，待确认。
4. 二期默认通过映射和抽查规则遵循审核流程变更说明，不在本文件新造选题状态。

### RS-R12 生成脚本

1. 默认从一个已选定选题进入脚本生成，必须展示选题标题和 ID。
2. 每个选题生成 2-3 版，沿用 R5。
3. 独立脚本允许选题为空，但必须在页面和数据中明确独立创建，且保留研究报告关联；沿用 R9/R10。
4. 脚本的版本历史、审核、已通过和已使用沿用一期；二期默认通过映射遵循审核说明。

## 七、采集结果引用规则

自动采集第二步已定义 `collection_result`。研究助手只保存引用关系中的 `collection_result_id` 和必要快照，不重定义对标账号、采集任务、采集记录、采集结果的字段、状态或来源适配器。采集原始事实默认 `is_ai_product=false`；研究报告对其进行摘要或推断后，新增内容必须 `is_ai_product=true`。

## 八、状态机和错误规则

### 8.1 研究任务状态

| 状态 | 触发 | 说明 | 确认度 |
|---|---|---|---|
| 待执行 | 创建任务 | 未启动 | 新增建议，待确认 |
| 检索中 | 开始研究/重试 | 正在获取来源 | 新增建议，待确认 |
| 整理中 | 检索达到整理条件 | 正在生成报告 | 新增建议，待确认 |
| 已完成 | 报告校验通过 | 报告可用 | 新增建议，待确认 |
| 失败 | 检索或整理失败 | 可查看错误并重试 | 新增建议，待确认 |

### 8.2 错误分类

任务级错误包括供应商不可用、授权/配额问题和系统异常；来源级错误包括 URL 不可访问、解析失败、合规不可访问和空响应。错误码、错误等级和是否自动重试均为新增建议，待确认。

## 九、权限与审核规则

管理员可创建、启动、重试任务、查看报告、沉淀资料、生成选题/脚本和主动发起抽查；成员沿用现有权限，不新增角色。研究报告和生成结果默认可用但保留 AI 标记、抽查、废弃和审核重启入口。审核模式开关、抽查比例和结果字段待确认。

## 十一、待确认事项

1. 检索源最终选型、成本、配额、稳定性和引用能力。
2. 检索任务的状态落库方案和“执行中+阶段字段”替代方案。
3. 中断恢复点、checkpoint 内容、重试上限和退避策略。
4. 报告章节/结论/摘要结构及引用缺失是否阻塞完成。
5. 外部 URL、采集结果、资料三类引用字段互斥规则。
6. 报告沉淀资料的默认状态、可信度、有效期和关联字段。
7. 报告生成选题的方向、批次和来源追溯映射。
8. 报告生成脚本的提示词快照、2-3 版输出和独立路径细节。
9. AI 结果轻量抽查比例、触发时机和审核状态映射。
10. 来源版权、全文保存、快照、删除和过期策略。
