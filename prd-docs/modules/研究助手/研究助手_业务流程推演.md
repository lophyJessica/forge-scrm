# 研究助手_业务流程推演

> 文件定位：研究助手模块动态沙盘——任务、阶段、报告、引用和内容生成链路推演
> 依据：研究助手主PRD、研究助手字段清单、研究助手_业务规则规格、二期总 PRD 5.2
> 推演关卡：覆盖正常研究、失败恢复、引用追溯、资料沉淀和选题/脚本生成后，才进入后续页面设计。

## 一、推演前提

当前使用人：操盘手（管理员）。

研究输入示例：

```text
topic=制造业企业如何通过短视频获得有效线索
objective=识别近期有效内容方法、对标动态和可验证的选题方向
time_window_start=2026-08-01 00:00:00
time_window_end=2026-08-25 23:59:59
scope=外部公开来源 + 资料库 + 自动采集结果
```

本流程中的外部 URL、检索供应商和返回内容均为示例；DeepSeek 联网、Tavily 等具体源必须待实测，不代表已确认依赖。

## 二、主流程步骤推演

### 步骤 1：创建研究任务

入口：登录 → 左侧菜单“研究助手” → “新建研究任务”。

操作：输入主题、研究目标、时间窗，勾选外部检索、资料库和自动采集结果，点击“创建任务”。

预期：

1. 主题和目标通过必填校验。
2. 任务创建成功，生成 `RT20260826-001`。
3. 状态为 `待执行`，不会在创建瞬间隐式调用外部来源。
4. 页面展示范围摘要、时间窗和“开始研究”按钮。

### 步骤 2：选择检索范围

建议范围数据：

```json
{
  "external_search": true,
  "material_ids": [301, 302],
  "collection_result_ids": [70001, 70002],
  "time_window_start": "2026-08-01T00:00:00+08:00",
  "time_window_end": "2026-08-25T23:59:59+08:00"
}
```

`scope_config` 的最终 JSON 结构、时间时区和 ID 快照策略为新增建议，待确认。资料和采集结果的引用权限继续由原模块规则控制。

### 步骤 3：开始研究与阶段进度

操作：点击“开始研究”。

预期：任务从待执行进入 `检索中`（新增建议，待确认）；页面显示已处理来源数、最近更新时间和阶段进度。若系统复用一期 `执行中`，则必须通过 `current_stage=检索中` 提供同等可见信息。

示例进度：

```text
task_no=RT20260826-001
status=检索中
current_stage=检索中
progress_percent=35
progress_message="已完成 7 个来源，正在读取行业报告"
checkpoint_data={"last_source_index":7,"saved_citation_count":6}
```

上述进度字段为新增建议，待确认。

### 步骤 4：联网检索与来源保存

系统按实际可用检索源执行，保存来源标题、URL、检索时间、来源类型和摘要/快照。

示例来源：

```text
source_kind=external_url
source_url=https://example.invalid/research/short-video-leads
source_title=企业短视频获客趋势观察
search_provider=待实测候选源
source_type=行业报告（新增建议，待确认）
cited_at=2026-08-26 10:02:00
```

同时引用第二步自动采集结果：

```text
source_kind=collection_result
collection_result_id=70001
source_snapshot="增长研究所：企业获客的三个误区"
```

预期：外部 URL 和采集结果均进入研究引用关系候选，不重设计采集表。

### 步骤 5：进入整理阶段

检索达到整理条件后，任务进入 `整理中`（新增建议，待确认）。页面展示已整理章节数、已形成结论数和最近更新时间。

示例：

```text
status=整理中
current_stage=整理中
progress_percent=70
progress_message="已整理 3 个章节，正在补充证据引用"
```

系统将检索来源、资料库条目和采集结果组织为报告上下文，模型产出的摘要和结论必须与来源事实分开。

### 步骤 6：生成研究报告

报告示例：

```text
report_id=RR20260826-001
research_task_id=RT20260826-001
title=制造业企业短视频获客研究
summary=整理近期获客内容方法与对标变化
is_ai_product=true
status=已完成
source_count=9
```

预期：报告有摘要、正文、章节、结论、生成追溯和研究任务关联；每个关键结论尽量关联外部 URL、采集结果或资料。报告的 `is_ai_product=true` 是一期字段语义的复用。

### 步骤 7：查看和引用回点

操盘手打开报告详情：

1. 查看摘要、章节和结论。
2. 点击外部 URL 引用，打开来源页面或展示来源快照。
3. 点击采集结果引用，返回第二步结果详情。
4. 点击资料引用，返回一期资料详情。
5. 查看引用所在章节、证据摘要和生成时间；增强字段为新增建议，待确认。

若来源不可用，报告保留已生成内容但明确引用不可用，不将不可访问来源显示为已验证事实。

### 步骤 8：沉淀资料库

操盘手点击“沉淀到资料库”，补齐资料分类、来源类型、来源链接、可信度、有效期等一期字段。

预期：

1. 目标资料沿用 `context/05` 字段。
2. 目标资料 `is_ai_product=true`，并关联 `report_id=RR20260826-001`（关联字段为新增建议，待确认）。
3. 报告原始引用关系仍保留。
4. 二期默认通过允许进入可用链路，但轻量抽查和原审核入口保留，精确状态映射待确认。

### 步骤 9：由报告生成选题

操盘手点击“生成选题”，选择业务方向“制造业获客”和专业方向“短视频获客”。

预期：报告和引用作为资料上下文；生成结果沿用 R4/R14，保留批次和 AI 原始响应，完全重复标题跳过；选题与报告关联字段为新增建议，待确认。

示例：

```text
topic_batch=T20260826-003
title=制造业短视频获客为什么有播放没线索
status=待筛选或二期默认通过映射（映射待确认）
reference_materials=RR20260826-001 + material:301
```

### 步骤 10：由报告生成脚本

默认路径：在已选定选题上点击“生成脚本”。

预期：

1. 页面显示选题标题和 ID，符合 R10。
2. 为该选题生成 2-3 版脚本，符合 R5。
3. 脚本保留研究报告和引用追溯，关联字段为新增建议，待确认。
4. 默认通过模式下可直接进入可使用路径，AI 产物仍可抽查。

独立路径：用户从报告详情直接点击“独立生成脚本”，页面明确选题为空；脚本仍关联报告，符合 R9/R10，后续可补关联。

## 三、异常分支推演

### 分支 A：检索源不可用

前置：候选检索源超时、返回空内容或不提供 URL。

预期：任务进入失败或保留可恢复的检索错误；保存失败源、错误码、错误信息和已经成功的来源；不伪造引用，不把空响应当作有效证据；管理员可重试或调整范围。错误码和部分结果保留方式为新增建议，待确认。

### 分支 B：任务中断并恢复

前置：任务在检索中浏览器关闭、服务重启或网络断开。

预期：服务端保留任务状态、已保存引用和 checkpoint；重新打开任务详情能显示最近进度；点击恢复/重试后从最近阶段继续或按确认策略重检。恢复入口、自动恢复和是否允许编辑范围待确认。

### 分支 C：整理阶段失败

前置：检索结果已保存，模型整理超时或输出结构校验失败。

预期：任务进入失败，阶段为整理中；检索来源仍可查看；重试优先复用已保存来源，不删除旧错误和旧 AI 响应；整理成功后生成已完成报告。

### 分支 D：报告生成失败

前置：整理阶段生成报告时超时或章节缺失。

预期：不显示已完成报告；保留任务、来源和失败原因；管理员可重试。报告是否允许保存草稿和章节级恢复为新增建议，待确认。

### 分支 E：引用来源过期/不可访问

预期：报告仍保留引用关系、URL 和必要快照；详情显示来源当前不可访问或已过期；不把报告结论改写为原始事实。快照保存范围和版权处理待确认。

## 四、页面与状态对应关系

| 页面/区域 | 主要实体 | 状态/动作 |
|---|---|---|
| 研究任务列表 | 研究任务 | 待执行/检索中/整理中/已完成/失败 |
| 新建研究任务 | 研究任务 | 填主题、目标、范围和时间窗 |
| 研究任务详情 | 研究任务 | 阶段进度、最近错误、恢复/重试 |
| 检索来源区域 | 研究引用关系 | 外部 URL、检索源和来源快照 |
| 研究报告详情 | 研究报告、研究引用关系 | 摘要、章节、结论、引用回点 |
| 资料沉淀动作 | 研究报告→资料 | 填一期资料字段、AI 标记 |
| 选题生成动作 | 研究报告→选题 | 方向、批次、完全重复去重 |
| 脚本生成动作 | 研究报告→脚本 | 选题关联、2-3 版、独立路径 |

## 六、流程走查清单

- [ ] 任务创建不隐式联网，开始研究由用户明确触发。
- [ ] 检索中、整理中阶段可见；可用执行中+阶段字段替代。
- [ ] 页面刷新、重新进入或任务中断后能读取服务端进度。
- [ ] 外部 URL、自动采集结果、资料三类引用均可追溯。
- [ ] 研究报告摘要、章节、结论和生成追溯可查看。
- [ ] 研究报告 `is_ai_product=true`，不覆盖原始来源事实。
- [ ] 报告沉淀资料继续填写一期有效期和可信度。
- [ ] 报告生成选题沿用完全重复去重。
- [ ] 报告生成脚本默认展示选题并生成 2-3 版。
- [ ] 独立生成脚本时选题明确为空且保留报告关联。
- [ ] 检索或整理失败保留错误，重试不丢失已保存来源。
- [ ] P1 周报、报告模板和推送记录不在本流程展开。

## 七、待确认事项

1. 研究阶段状态正式落库还是复用执行中+阶段字段。
2. 任务 checkpoint、恢复位置和重试策略。
3. 检索源供应商、成本、配额和真实引用能力。
4. 外部来源合规、版权、快照和删除处理。
5. 报告章节级引用和引用缺失的完成条件。
6. 报告与资料、选题、脚本的关联字段。
7. AI 产物默认通过后的抽查和撤回状态映射。
