## 三、用例 RS-TC-01：正常研究全流程

### 场景

操盘手希望研究制造业企业短视频获客，结合外部公开来源、资料库和自动采集结果形成报告。

### 前置条件

1. 管理员已登录。
2. 资料 301、302 为一期可用资料。
3. 自动采集结果 70001 已成功落库，原始结果 `is_ai_product=false`。
4. 至少一个检索源已通过合规和可用性实测；具体供应商仍待确认。

### 操作步骤

1. 输入主题和研究目标。
2. 选择外部检索、资料 301/302 和采集结果 70001。
3. 创建任务并确认状态为 `待执行`。
4. 点击开始研究，观察 `检索中` 进度。
5. 等待来源保存完成，观察 `整理中` 进度。
6. 打开生成的报告和引用。

### 预期结果

1. 任务编号为 `RT20260826-001`，创建后不隐式联网。
2. 任务经历待执行→检索中→整理中→已完成。
3. 报告 `RR20260826-001` 有摘要、正文/章节、结论和生成追溯。
4. 报告 `is_ai_product=true`。
5. 引用至少包含外部 URL、采集结果 70001 或资料 301/302 中实际使用的来源，并能回点。
6. 采集结果 70001 仍是原始事实，不被报告覆盖。

### 关键数据示例

```text
research_task:
task_no=RT20260826-001 status=已完成 topic=制造业企业如何通过短视频获得有效线索
current_stage=整理中→完成 progress_percent=100 retry_count=0

research_report:
report_id=RR20260826-001 research_task_id=RT20260826-001
title=制造业企业短视频获客研究
summary=整理近期获客内容方法与对标变化
is_ai_product=true source_count=5 status=已完成

research_citation:
id=501 report_id=RR20260826-001 source_kind=external_url
source_url=https://example.invalid/research/short-video-leads
source_title=企业短视频获客趋势观察

research_citation:
id=502 report_id=RR20260826-001 source_kind=collection_result

```

## 四、用例 RS-TC-02：检索阶段失败与重试

### 场景

检索源在任务运行期间超时，任务未能完成全部检索；管理员稍后重试。

### 前置条件

任务已创建并进入 `检索中`；已保存来源 2 个；第三个来源返回超时。

### 操作步骤

1. 查看任务详情。
2. 确认失败阶段为检索中，错误为来源超时。
3. 点击重试，不修改主题。
4. 观察任务回到检索中，再进入整理中。

### 预期结果

1. 任务不显示已完成报告。
2. 已保存的 2 个来源和引用关系继续存在。
3. 保存最近错误和重试次数，旧错误不被静默覆盖。
4. 重试成功后补充来源，任务进入整理中。
5. 不可用来源不生成伪造 URL 或空引用。

### 关键数据示例

```text
research_task:
task_no=RT20260826-002 status=失败 current_stage=检索中
last_error_code=SEARCH_TIMEOUT retry_count=0

saved_citations=2
retry_action:
from=失败 to=检索中 retry_count=1
new_citation_id=601 source_url=https://example.invalid/source/3
```

`last_error_code`、`current_stage` 和重试计数映射为新增建议，待确认。

## 五、用例 RS-TC-03：整理阶段失败与重试

### 场景

检索已成功，模型整理时输出截断或章节缺失；管理员重试整理。

### 前置条件

任务已保存 5 个来源，进入 `整理中`；报告结构校验失败。

### 操作步骤

1. 查看任务阶段进度和整理错误。
2. 确认来源和引用仍可访问。
3. 点击重试。
4. 系统复用已保存来源重新整理。
5. 打开报告详情。

### 预期结果

1. 任务先进入失败，阶段仍记录为整理中。
2. 已保存引用和原始来源不删除。
3. 旧 AI 原始响应保留，重试结果形成新的可追溯生成记录；具体存储方式待确认。
4. 整理成功后任务为已完成，报告有摘要、章节和结论。
5. 报告 `is_ai_product=true`。

### 关键数据示例

```text
research_task:
task_no=RT20260826-003 status=失败 current_stage=整理中
last_error_code=REPORT_SCHEMA_INVALID retry_count=1

research_report_attempt:
attempt_no=1 raw_ai_response={"sections":[{"title":"趋势"}]} result=failed
attempt_no=2 raw_ai_response={"sections":[{"title":"趋势"},{"title":"建议"}]} result=success
```

`research_report_attempt` 为新增建议，待确认；不得写入真实密钥或供应商凭据。

## 六、用例 RS-TC-04：报告沉淀资料库并标记 AI 产物

### 场景

操盘手认为报告适合长期复用，将报告沉淀为资料库条目。

### 前置条件

报告 `RR20260826-001` 已完成，有引用关系和摘要。

### 操作步骤

1. 打开报告详情。
2. 点击“沉淀到资料库”。
3. 填写资料分类“商业研究结论”、来源类型“报告/研究”（具体枚举沿用一期，映射待确认）、可信度“中”、有效期起止。
4. 保存并打开资料详情。

### 预期结果

1. 资料条目使用一期标题、内容、资料分类、来源链接、可信度、有效期和状态字段。
2. 资料 `is_ai_product=true`，明确是研究报告生成的 AI 产物。
3. 资料保留报告 ID 和引用来源关联；关联字段为新增建议，待确认。
4. 原始采集结果 70001 和外部来源不被改写。
5. 二期默认通过允许进入可用路径，但轻量抽查和原审核入口保留，精确状态映射待确认。

### 关键数据示例

```text
material:
id=501 title=制造业企业短视频获客研究
content=（报告正文快照）
source_type=报告/研究（枚举映射待确认）
source_link=https://example.invalid/research/short-video-leads
credibility=中 valid_from=2026-08-26 valid_to=2026-11-26
status=已生效 is_ai_product=true
source_report_id=RR20260826-001（新增建议，待确认）
```

## 七、用例 RS-TC-05：报告生成选题与脚本

### 场景

操盘手从报告生成一批选题，再为已选定选题生成脚本。

### 前置条件

1. 报告 `RR20260826-001` 已完成。
2. 资料沉淀或报告上下文可被选题生成使用。
3. 历史选题中已有标题“制造业短视频获客的三个误区”。

### 操作步骤

1. 点击“生成选题”。
2. 选择业务方向“制造业获客”、专业方向“短视频获客”。
3. 生成 3 条候选，其中 1 条与历史完全重复。
4. 对新选题执行一期选定动作或按二期默认通过映射进入可用路径。
5. 点击“生成脚本”，观察选题关联。
6. 选择独立生成脚本路径，观察选题为空但报告关联保留。

### 预期结果

1. 报告和引用作为选题生成上下文。
2. 完全重复标题按 R4/R14 跳过；语义近似不在本用例强制合并。
3. 新选题保留批次、AI 原始响应和研究报告来源；报告关联字段待确认。
4. 基于选题生成脚本时显示选题 ID 和标题，生成 2-3 版，符合 R5/R10。
5. 独立脚本的选题为空，页面明确独立创建，仍保留报告关联，符合 R9。
6. 选题、脚本和报告的 AI 产物状态可供轻量抽查。

### 关键数据示例

```text
topic_batch:
batch_no=T20260826-003 direction=制造业获客 specialty=短视频获客
reference_materials=RR20260826-001 + material:301
dedupe_skipped=1
topic_id=801 title=制造业短视频获客为什么有播放没线索
status=已选定（或默认通过映射，映射待确认）
source_report_id=RR20260826-001（新增建议，待确认）

script_set:
script_ids=901,902,903 topic_id=801 version_no=1,2,3
status=已通过（或默认通过映射，映射待确认）
source_report_id=RR20260826-001（新增建议，待确认）

independent_script:
script_id=904 topic_id=NULL independent_creation=true
source_report_id=RR20260826-001（关联字段新增建议，待确认）
```

## 十、待确认事项

1. 检索源的真实返回样例、引用粒度、成本和合规边界待实测。
2. `检索中`/`整理中`是否正式落库，或复用执行中+阶段字段待确认。
3. 任务中断恢复点、重试上限和报告整理尝试存储方式待确认。
4. 报告章节/结论级引用是否必须硬校验待确认。
5. 报告沉淀资料的状态、可信度、有效期默认策略和关联字段待确认。
6. 报告生成选题/脚本的来源字段和默认通过状态映射待确认。
