# 脚本库_Demo_详情与版本页

> 文件定位：脚本详情、版本历史、差异和回退页面规格
> 覆盖实现：ScriptDetail.tsx / ScriptVersions.tsx
> 路由：`/scripts/:id`、`/scripts/:id/versions`

## 一、详情页 `/scripts/:id`

卡片标题为“脚本 #id · v当前版本”，右上按状态显示版本历史、修改、提交审核、管理员审核、标记已使用、废弃。

| 区域 | 展示 |
|---|---|
| 描述区 | 状态、当前版本、来源选题、语言风格、内容要素、引用资料、创建时间、最后修改 |
| 正文区 | Card 内 pre，保留换行 |
| 来源选题 | 有 topic_id 可点击到 `/topics/:id`；空值显示独立创建 |
| 审核 | 待审核且管理员显示通过/驳回 |
| AI/追溯 | 当前详情未独立展示 AI 原始响应按钮 |

## 二、版本页 `/scripts/:id/versions`

```text
标题：脚本 #id 版本历史
顶部：左版本 Select / 对比 / 右版本 Select / 查看差异
表格：版本、备注、修改人、修改时间、查看快照、回退
```

### 2.1 查看差异

- 默认在版本数≥2 时选倒数第二和最后一个版本。
- 点击“查看差异”请求 `/scripts/:id/diff?left=&right=`。
- Modal 展示 diff；两版本一致时显示“（两版本内容一致）”。

### 2.2 查看快照

- 点击任一版本的“查看快照”打开 Modal。
- 显示 `content_snapshot`，最大高度 520，可滚动。

### 2.3 回退

- `PERM.脚本版本回退` 通过时显示回退按钮。
- Popconfirm 确认后 POST `/scripts/:id/rollback`。
- 成功提示“已回退到 vN（生成新版本并保留回退记录）”，刷新历史。

## 四、独立创建/编辑与审核页

实际 `ScriptForm.tsx` 路由为 `/scripts/new` 和 `/scripts/:id/edit`：选题可选、风格必填、内容要素多选、引用资料可选、正文必填；编辑模式增加修改备注输入。`ScriptReview.tsx` 路由 `/scripts/review`：查询待审核脚本，展开正文，管理员点击通过/驳回。

## 五、实现差异

- 当前独立编辑页加载所有选题，而生成页只加载已选定；业务规则以主 PRD 为准。
- `note` 字段尚未由 context 确认，已在字段清单标注待确认。
