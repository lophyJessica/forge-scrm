# 脚本库_Demo_独立创建与审核页

> 文件定位：脚本独立创建/编辑、审核队列页面补充规格
> 覆盖实现：ScriptForm.tsx / ScriptReview.tsx

## 一、独立创建/编辑

| 控件 | 当前实现 |
|---|---|
| 来源选题 | 可选 Select，独立创建允许为空 |
| 语言风格 | 必填，meta `script_style` |
| 内容要素 | 多选，meta `content_element` |
| 引用资料 | 可选，仅加载已生效资料 |
| 正文 | TextArea 14 行，必填且不能空白 |
| 修改备注 | 仅编辑模式出现，最大200；字段待确认 |
| 保存/取消 | 保存后回详情，取消返回上一页 |

## 二、审核队列 `/scripts/review`

- 请求 `/scripts?status=待审核&page_size=100`。
- 表格列：ID、正文摘要、来源选题、语言风格、版本、操作。
- 展开行显示完整正文。
- 通过调用 `/scripts/:id/review {approved:true}`，状态已通过。
- 驳回调用同接口 `approved:false`，状态已废弃。
- 页面标题明确“一期仅管理员”。
