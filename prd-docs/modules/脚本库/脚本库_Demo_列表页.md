# 脚本库_Demo_列表页

> 文件定位：现有 `ScriptList.tsx` 页面规格
> 路由：`/scripts`

## 一、页面结构

```text
Card：脚本列表
├─ 右上：[独立创建] [基于选题生成]
├─ 查询：正文关键词 / 选题 ID / 语言风格 / 状态 / 查询 / 重置
└─ 表格：分页20条、行内状态动作
```

## 二、表格列

| 列 | 字段/行为 |
|---|---|
| ID | id |
| 正文摘要 | content 前60字，点击进入详情 |
| 来源选题 | topic_title/topic_id；为空显示“独立创建” |
| 语言风格 | style |
| 版本 | current_version 显示 vN |
| 状态 | status Tag：草稿/待审核/已通过/已使用/已废弃 |
| 操作 | 详情、版本、提交审核、标记已使用、废弃 |

## 三、查询与操作

- `topic_id` 可从 `/scripts?topic_id=` 回填，供选题详情跳转。
- 草稿显示提交审核；已通过显示标记已使用；草稿/待审核/已通过显示废弃。
- 版本按钮跳 `/scripts/:id/versions`。
- API 错误由全局拦截器提示，分页每页 20。
