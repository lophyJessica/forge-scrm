# 脚本库字段清单

> 文件定位：脚本库字段 SSOT 展开版
> 权威：`context/05-术语与字段口径.md` §4.5；类型映射参照 `prd-docs/核心字段清单.md` §3

## 一、脚本 script

| 字段 | 类型 | 必填 | 说明/约束 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| topic_id | bigint FK | 条件 | 基于选题创建时必填并显示；独立创建时可空、可后补 |
| content | longtext | ✅ | 脚本正文，非空白 |
| style | enum | ✅ | 专业严谨/轻松口语/讲故事 |
| content_elements | json | ✅ | 案例/数据/个人观点 |
| current_version | int | ✅ | 当前版本号 |
| status | enum | ✅ | 草稿/待审核/已通过/已使用/已废弃；草稿派生 |
| reviewer_id | bigint FK | 条件 | 一期审核人仅管理员 |
| reviewed_at | datetime | 条件 | 审核时间 |
| created_by | bigint FK | ✅ | 创建人 |
| created_at | datetime | ✅ | 创建时间 |
| modified_by | bigint FK | ✅ | 最后修改人 |
| modified_at | datetime | ✅ | 最后修改时间 |
| material_refs | json | 否 | 可选资料追溯 |
| prompt_version_snapshot | json | 否 | 可选提示词快照 |

## 二、脚本版本 script_version

| 字段 | 类型 | 必填 | 说明/确认度 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| script_id | bigint FK | ✅ | 所属脚本 |
| version | int | ✅ | 每次保存递增 |
| content_snapshot | longtext | ✅ | 正文快照 |
| changed_by | bigint FK | ✅ | 修改人 |
| changed_at | datetime | ✅ | 修改时间 |
| note | varchar(200) | 否 | ⚠️ 新增建议，待确认；前端编辑页已提供“修改备注” |

## 三、页面 DTO 映射

| 页面 | 主要字段 |
|---|---|
| 列表 | id/content 摘要/topic_id/topic_title/style/current_version/status |
| 生成结果 | id/content 摘要/current_version/status/ai_raw_archive |
| 详情 | 状态、版本、来源选题、风格、内容要素、引用资料、创建/修改时间 |
| 版本历史 | version/note/changed_by/changed_at/content_snapshot |

`topic_title`、`ai_raw_archive`、差异文本属于接口返回 DTO，不新增业务字段。版本差异是对两个 `content_snapshot` 的计算结果。

## 四、枚举与状态

| 枚举 | 值来源 |
|---|---|
| style | 专业严谨/轻松口语/讲故事 |
| content_elements | 案例/数据/个人观点 |
| status | 草稿/待审核/已通过/已使用/已废弃 |

## 五、待确认字段

- `script_version.note`：⚠️ 新增建议，待确认；现有页面可输入，但不是一期已确认业务字段。
- 独立提示词版本实体：⚠️ 新增建议，待确认；当前使用快照字段，不建独立表。
