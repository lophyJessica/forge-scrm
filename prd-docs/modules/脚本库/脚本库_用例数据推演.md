# 脚本库_用例数据推演

> 文件定位：脚本库用例、状态快照、版本走查

## 一、核心用例表

| 用例 | 前置 | 操作 | 期望结果 |
|---|---|---|---|
| TC-S01 基于选题生成 | 有已选定选题 | 选题→风格→生成 3 版 | 生成 3 条草稿，显示选题 |
| TC-S02 生成版数边界 | 已登录 | 输入 1 或 4 | 前端/后端拒绝，范围 2-3 |
| TC-S03 独立创建 | 无选题 | 独立创建并保存 | topic_id 为空，状态草稿 |
| TC-S04 后补关联 | 已有独立脚本 | 编辑选择选题 | topic_id 写入，来源显示选题 |
| TC-S05 提交审核 | 草稿 | 点击提交审核 | 状态→待审核 |
| TC-S06 管理员通过 | 待审核 | 管理员点击通过 | 状态→已通过 |
| TC-S07 管理员驳回 | 待审核 | 管理员点击驳回 | 状态→已废弃 |
| TC-S08 标记已使用 | 已通过 | 点击标记已使用 | 状态→已使用 |
| TC-S09 非已通过标记 | 待审核/已废弃 | 点击标记已使用 | 操作被拒绝 |
| TC-S10 修改版本 | v1 | 改正文保存 | v2 产生，v1 快照保留 |
| TC-S11 对比版本 | ≥2 版本 | 选左右版本查看差异 | 显示 diff |
| TC-S12 回退 | v1/v2 | 从 v2 回退 v1 | 当前正文=v1，生成新版本 |
| TC-S13 空正文 | 编辑页 | 清空正文保存 | 拒绝保存 |
| TC-S14 资料过滤 | 有未生效资料 | 生成页打开资料下拉 | 仅显示已生效 |

## 二、状态快照

```text
脚本 #301：topic_id=101《制造业获客的三个误区》
初始：草稿，current_version=1
提交：待审核，current_version=1
管理员通过：已通过
人工使用：已使用
```

## 三、版本快照

```text
v1：开头从客户痛点切入
v2：修改开头钩子，note=“调整开头钩子”（字段待确认）
回退 v1：
  当前正文恢复为 v1
  新增 v3，content_snapshot=v1 内容
  v1/v2 仍可查看
```

## 四、独立创建快照

```text
脚本 #302：topic_id=null，status=草稿
编辑补录 topic_id=102
提交后：待审核，详情显示选题《低成本获客》
```
