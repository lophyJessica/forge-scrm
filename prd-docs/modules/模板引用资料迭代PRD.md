# 模板引用资料（material_combo 闭环）— 二期迭代需求

> 状态：已确认，待开发
> 日期：2026-08-28
> 提出人：梁庭飞（姐夫/操盘手）
> 关联：核心字段清单 §提示词模板（material_combo 已定稿）；选题库主PRD §生成流程

## 一、背景与问题

用户创建提示词模板时，无法关联资料库条目；生成时只能当场手动勾选资料。资料内容更新后，用户需在提示词里手动复制粘贴，维护成本高。

需求原话：「我们做了资料库，我想做的就是在提示词里调用资料库内容，类似飞书表格的引用字段」「不然就要复制到提示词里，太长了」。

## 二、设计澄清（重要）

`material_combo`（固定关联资料组合）在核心字段清单 §提示词模板 中早已定稿，后端模型/schema/路由已支持存储。**本需求不是新功能，是把设计补完**：补齐「生成时读取合并」和「前端配置入口」两处缺失。

## 三、需求内容

### 3.1 模板配置入口（前端）

- 模板新建/编辑表单（admin/PromptTemplates.tsx、analysis/PromptTemplates.tsx 两处）新增「引用资料」多选区块
- 资料选择器只展示「已生效」状态资料（R1：审核后才能使用）
- 支持按资料分类/标签筛选后勾选
- 保存时随模板提交 `material_combo`（资料 id 数组）

### 3.2 生成时读取合并（后端）

- `build_prompt`（topic_service.py）模板分支：取 `template.material_combo`，与用户当场勾选的 `material_ids` **合并去重**后传入 `build_material_block`
- 同样规则适用：引用资料必须「已生效」，否则报错（R1，现有校验逻辑复用）
- 脚本生成、数据分析任务如走模板链路，同样处理（最小改动优先，先覆盖选题生成）

### 3.3 快照与追溯

- 生成快照（snapshot）在 `content_snapshot` 基础上补记：`material_combo_snapshot`（当时引用的资料 id + 标题 + 内容），保证历史生成可追溯当时用了什么资料
- 引用语义 = **实时引用**：每次生成都读资料当前最新内容（非复制快照），资料更新后下次生成自动生效，模板无需改动

### 3.4 交互文案

- 模板表单区块标题：「引用资料（生成时自动注入最新内容）」
- 帮助文案：「勾选后，每次使用该模板生成时会自动附带这些资料的最新内容；资料更新无需修改模板」

## 四、边界（不做）

- 不做向量检索/自动匹配（RAG）：一期资料量级下人工勾选够用，二期资料量大后再评估
- 不做占位符自定义插入位置：资料统一以「参考资料」区块注入提示词（沿用 build_material_block 现有格式）
- 不改审核规则（R8 不受影响：引用只是读取资料，不产生新资料）

## 五、验收标准

1. 模板 A 勾选资料 X（已生效）→ 用模板 A 生成选题（当场不选资料）→ 生成请求的 user_prompt 包含资料 X 内容
2. 资料 X 内容更新（重新审核生效）→ 再次生成 → 注入的是新内容
3. 模板 A 引用的资料被停用 → 生成时报错提示「参考资料必须为已生效状态」，不静默跳过
4. 当场勾选资料 Y + 模板引用资料 X → 两者都注入，无重复
5. 快照记录包含引用资料的标题与内容，历史任务详情可查
6. 不勾选任何资料的行为与现状完全一致（回归无损）
