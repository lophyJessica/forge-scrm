# 权限账号_Demo_登录与个人账号页

> 文件定位：现有 Login.tsx / Profile.tsx / MainLayout.tsx 页面规格
> 路由：`/login`、`/profile`；登录后嵌入主框架

## 一、登录 `/login`

- 页面居中 Card，标题“姐夫新媒体运营系统”。
- 说明文字：账号密码登录，一期不支持扫码/验证码。
- 表单：账号 Input、密码 Password、登录按钮。
- 登录调用 auth store；成功后若 `must_change_password` 为 true，提示尽快修改密码，并跳 `/`。
- 失败由接口拦截器提示；401 清理 token 并回登录。

## 二、个人账号 `/profile`

### 我的账号 Card

展示账号、角色 Tag、状态、数据范围、功能权限。管理员显示“全部”，成员显示显式授权列表。

### 修改密码 Card

原密码、新密码（至少6位）、提交。POST `/auth/change-password` 成功后提示并登出，跳 `/login`。

## 三、主框架权限表现

- 登录后侧边栏按角色生成菜单。
- 管理员显示权限管理；成员不显示。
- 顶栏显示角色 Tag、账号下拉、修改密码和退出登录。
- 未登录访问主框架重定向 `/login`。
