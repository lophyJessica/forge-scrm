# 权限账号字段清单

> 文件定位：权限账号字段 SSOT 展开版
> 权威：`context/05-术语与字段口径.md` §4.8；类型映射参照 `prd-docs/核心字段清单.md` §5

## 一、用户 user

| 字段 | 类型 | 必填 | 说明/确认度 |
|---|---|---|---|
| id | bigint PK | ✅ | 主键 |
| username | varchar(100) | ✅ | 唯一登录账号（D7） |
| password_hash | varchar(200) | ✅ | 密码哈希，不保存明文（D7） |
| role | enum | ✅ | 管理员/成员 |
| status | enum | ✅ | 启用/停用 |
| functional_permissions | json | ✅ | 管理员分配的功能权限集合 |
| data_scope | json | ✅ | 全量/指定资料分类/指定数据源 |
| created_by | bigint FK | ✅ | 创建人 |
| created_at | datetime | ✅ | 创建时间 |
| last_login_at | datetime | 否 | ⚠️ 新增建议，待确认；前端列表展示 |

## 二、数据范围结构

| 字段 | 类型 | 确认度 |
|---|---|---|
| type | enum | ✅ 全量/指定 |
| material_class_ids | json 数组 | ✅ 条件：type=指定 |
| data_source_ids | json 数组 | ✅ 条件：type=指定 |

## 三、前端权限码映射

当前前端从 `/meta/permissions` 获取权限项，已使用权限码包括：

| 权限码 | 页面动作 | 口径 |
|---|---|---|
| material.delete | 删除资料 | context/06 成员待确认 |
| tag.create | 创建标签 | context/06 成员待确认 |
| topic.generate/create/update | 选题生成/新增/修改 | context/06 部分待确认 |
| script.update/version.view/version.rollback | 脚本修改/版本查看/回退 | context/06 待确认 |
| rawdata.input | 数据录入/导入 | context/06 成员待确认 |
| analysis.task.execute | 分析任务执行 | context/06 成员待确认 |
| analysis.result.review | 分析结果审核 | context/06 成员待确认 |
| analysis.writeback | 回写/反哺 | context/06 成员待确认 |
| prompt.config | 提示词配置 | 由管理员授权 |

权限码是实现映射，不新增角色枚举；管理员恒拥有全部权限，成员按显式授权。

## 四、页面 DTO 映射

| 页面 | 字段 |
|---|---|
| 登录响应 | access_token/token_type/expires_in/must_change_password/user |
| 成员列表 | id/username/role/status/functional_permissions/data_scope/last_login_at |
| 成员编辑 | username/password/role/functional_permissions/scope_type/material_class_ids/data_source_ids |
| 个人账号 | username/role/status/data_scope/functional_permissions |

`access_token`、`expires_in`、`must_change_password` 为认证接口返回值；不是 user 业务表字段。

## 五、待确认字段

- `last_login_at`：⚠️ 新增建议，待确认。
- 账号锁定计数、失败次数、审计日志字段：⚠️ 新增建议，待确认；一期不建审计实体。
- 自定义角色实体：二期，不作为一期字段。
