# 权限账号_Demo_成员列表页

> 文件定位：现有 `Users.tsx` 成员与权限列表页面规格
> 路由：`/admin/users`，由 RequireAdmin 保护

## 一、页面结构

```text
Card：成员与权限
├─ 说明 Alert：管理员全部权限、成员显式授权、一期不设成员上限
├─ 右上：[新增成员]
└─ 表格：ID、账号、角色、状态、功能权限、数据范围、最近登录、操作
```

## 二、列表数据

GET `/users?page_size=200`，表格无分页控件。角色 Tag：管理员 gold、成员 blue；状态：启用 green、停用 default。

## 三、行内操作

| 操作 | 行为 |
|---|---|
| 编辑 | 打开成员编辑 Modal |
| 重置密码 | 打开重置密码 Modal |
| 停用/启用 | POST `/users/:id/disable|enable` 后刷新 |

## 四、列展示

- 功能权限：管理员显示“全部”；成员显示权限标签或“—”。
- 数据范围：显示 `全量` 或 `指定`。
- 最近登录：`last_login_at` 为空显示“—”；字段待确认。

## 六、权限与空态

- 路由由 `RequireAdmin` 保护，非管理员显示 403。
- 空列表使用 Ant Design Table 默认空态。
- API 错误由全局拦截器提示。
