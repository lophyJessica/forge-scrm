# Forge 新媒体运营系统 主PRD

> 状态：✅ 已定稿（首轮 7+1 与第二轮 9 项均已于 2026-08-24 回写）
> 角色：主PRD
> 权威层级：context/ > templates/ > 本文件

## 1. 产品概述

面向操盘手（管理员）的新媒体运营系统，一期实现：

- 资料库：手动添加/CSV/TXT 导入、自由标签、搜索调用、审核、有效期/可信度管理；
- 选题库：按方向批量生成（每方向10条）、跨批次完全重复去重、历史保留、人工筛选；
- 脚本库：基于选题生成 2-3 版脚本（偶尔独立创建），人工挑选/修改、版本对比回退、管理员简单审核、人工标记已使用；
- 数据入口：手动录入 + CSV/TXT 导入；自动采集仅作架构预留；
- 数据分析：基础分析框架与状态流转、人工审核、回写资料库/反哺选题；深度指标二期。

## 3. 用户故事

1. 作为操盘手（管理员），我要手动添加一条商业研究结论，并选择分类、填写来源、有效期和可信度，以便后续生成选题时引用。
2. 作为操盘手，我要手动添加或通过 CSV/TXT 导入资料和账号数据，以便在尚无视频号账号时完成一期运营闭环。
3. 作为操盘手，我要按方向批量生成10个选题，并由系统过滤与历史完全重复的标题；语义相近由人工判断。我可以人工修改选题，但一期不需要版本历史（D8）。
4. 作为操盘手，我要人工筛选选题，标记可用/废弃，以便保证内容质量。
5. 作为操盘手，我要基于选定选题生成2-3个脚本版本，以便挑选最佳表达；偶尔也要能独立创建脚本，此时选题可为空并可后补关联。
6. 作为操盘手，我要查看脚本所属选题、对比回退历史版本，并把已通过且实际使用的脚本人工标记为已使用。
7. 作为操盘手，我要录入/导入基础数据，运行通用分析任务，经审核后回写资料库、生成新选题；深度指标分析后续迭代。
8. 作为管理员，我要通过账号密码登录，并创建不限业务数量的成员账号、分配角色和数据权限。

## 4. 核心流程

- 资料入库 → 审核 → 生效 → 被引用：见 `context/02-核心业务流程.md` §2
- 选题生成 → 去重 → 筛选 → 可用 → 进脚本：见 `context/02-核心业务流程.md` §3
- 脚本生成 → 基于选题（偶尔独立）→ 2-3版 → 挑选 → 修改（保留历史版本）→ 管理员审核：见 `context/02-核心业务流程.md` §4
- 手动录入/CSV 导入 → 基础分析 → 审核 → 回写/反哺：见 `context/02-核心业务流程.md` §5

## 5. 状态机

- 资料：草稿 → 待审核 → 已生效 → 已停用/已过期/已废弃
- 选题：待筛选 → 已选定(派生) → 已生成脚本 → 已使用(派生)/已废弃
- 脚本：草稿(派生) → 待审核 → 已通过 → 已使用(人工标记)/已废弃；**每次修改生成新版本，保留历史可回退（4.10）**
- 分析任务：待执行 → 执行中 → 已完成 → 待审核 → 已确认/已废弃（失败可重试）

详见 `context/04-业务规则与状态机.md`。

MVP 核心实体：资料分类/资料条目/资料标签及关联/提示词模板/选题及可选资料引用/脚本/脚本版本/数据源/原始数据/分析任务及输入引用/分析结果/用户。选题版本表已明确二期；资料版本、独立提示词版本仍为待确认扩展实体。

关系与字段：见 `context/03-业务实体与关系.md`、`context/05-术语与字段口径.md`。

## 8. 验收标准（MVP）

### 8.1 必须验收

- [ ] 资料手动添加 → 分类 → 标签（可直接新建）→ 审核 → 生效 → 可被搜索；
- [ ] 按方向批量生成10条选题，跨批次完全重复去重有效；
- [ ] 选题人工筛选（可用/废弃）；
- [ ] 选题可人工修改并保存当前内容，且不生成选题版本历史（D8）；
- [ ] 基于选题生成2-3版脚本时显示所属选题；独立创建时选题为空且允许后补关联；
- [ ] 脚本状态流转（待审核→已通过/已废弃；已通过→人工标记已使用）；
- [ ] 脚本修改后保留历史版本，可对比回退；
- [ ] 手动录入或 CSV/TXT 导入基础数据 → 创建分析任务 → 通用结构化输出 → 人工审核；
- [ ] 分析结果可回写资料库、生成新选题；
- [ ] 管理员可用账号密码登录、创建成员账号并分配基础权限；成员数量不设业务上限；
- [ ] MySQL 数据持久化，重启不丢。

### 8.2 架构预留检查（不计入 MVP 通过条件）

- [ ] 自动采集数据源、任务、接口具备扩展位置，但不要求接入平台或拉取真实数据。

### 8.3 非功能

- 服务重启后自动恢复；
- 生成任务失败可重试，保留错误记录；
- AI 原始响应留档（仅 AI 批量生成/分析任务路径；独立选题/脚本创建不要求）；
- 敏感 key 不出现在日志；
- VPS 升级后 4C+4G 资源占用稳定（MySQL+API+Nginx+任务）。
