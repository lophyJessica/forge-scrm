## 模块套件规范（对齐 forge-erp 采购入库单）

每个业务模块 = 一个文件夹，含：

| 文件 | 只管什么 | 禁止写什么 |
|---|---|---|
| `{模块}主PRD.md` | 背景、范围、定位、场景、规则摘要、验收 | 重复定义字段枚举/必填性 |
| `{模块}字段清单.md` | 字段唯一定义（SSOT 展开） | 页面布局、按钮文案 |
| `{模块}_业务规则规格.md` | 状态机、校验、权限、计算规则 | 重复写字段本体 |
| `{模块}_业务流程推演.md` | 动态沙盘：步骤 + 真实示例数据 | 与用例推演重复的细算账 |
| `{模块}_用例数据推演.md` | 带数字验证：公式、状态快照、走查清单 | UI 控件规格 |
| `{模块}_Demo_列表页.md` | 页面结构、控件、交互、Mock | 字段枚举、计算规则 |
| `{模块}_Demo_*页.md` | 其他页面（生成/详情/编辑） | 同上 |
